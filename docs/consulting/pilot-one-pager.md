# Pilot 一頁紙（請老闆簽這一頁）

> 範本。填空後印出一頁，由董事長室簽署。**沒有簽這一頁，不開始 pilot。**
> 這一頁用團隊層（分身）的做法與指標；若公司用 LINE 或 Teams（團隊層不支援），請改走 plugin pilot（兩位種子使用者、合成資料 `/quote`），並另訂指標，**不要借用本頁指標**。

```
【Pilot 一頁紙】  公司：________  版本：____  日期：________

1. 目標（一句話，不寫「省多少人 / 錢」）
   讓 ______（職稱）與 ______（職稱）用副駕看得更多、更快發現漏洞；判斷仍由人做。

2. 兩個職位（用職稱，不寫姓名）
   ① ______部主管    ② ______部主管
   各自通過「需要分身嗎？」閘門，紀錄編號：______ / ______

3. 期間：六週（____ 至 ____）。第六週結束開檢討會，決定「續行 / 調整 / 停用」。

4. 資料：只用 T1 以下（內部 SOP、排程摘要、已去識別的 NCR）。
   圖紙、BOM、報價與金額、客戶名、人名、聯絡方式一律不放。T3 不進任何頻道，由人自行擋住。
   使用雲端模型：我們已知內容會送到模型供應商，且已查客戶合約  ☐ 已查

5. 能力上限：草稿（draft）。不寫入任何系統、不對外發送、不替人做決定。
   外包既有工作類的能力：☐ 不開　☐ 開 1 項（核准人：______，複審日：______）

6. 只量三件事（每週手工記錄，粒度到部門，不記個人）
   a. 人修改 AI 結論的比例（大於 0 是健康的；連續 N 週為 0 要停下來看）
   b. 人先寫（例如 8D 的 D4）的比例
   c. 每週 review 出席率
   不量「省了多少小時」。指標不作為人力或績效依據。

7. 角色（職稱，三者互不兼任，也都不是顧問）
   核准人：______   金鑰保管人：______   稽核檢查點簽收人：______

8. 何時停下來（任一成立就暫停並開會）
   指標 a 連續 N 週為 0；出席率連續 N 週低於 ____；有人說「AI 做就好不用看」；
   T3 或未核准 T2 內容出現；指標被用於人事決定。任何同仁可要求暫停其職位的分身。

9. 六週後
   ☐ 續行（重跑閘門、範圍重新簽核）　☐ 調整後再試　☐ 停用：撤銷 token 與金鑰、
   依資料條款處理、出具停用報告。無論哪一種，都要出一份如實的結案報告（含錯誤回答與限制）。

10. 本 pilot 不包含：ERP / MES 串接、地端模型、LINE / Teams、T2 / T3 資料、正式上線。

簽署：董事長室 ________  日期：________      顧問（見證）________  日期：________
```

## 使用說明（顧問自用，不印給老闆）

- 欄位 6 的三項指標就是驗收標準 A4 的內容；表格見 `docs/adoption-guide.md` 團隊段的「每週記錄表」†。
- 欄位 7 的角色分離不可妥協：顧問若同時持金鑰又簽收，稽核檢查點就沒有意義。
- 欄位 8 的門檻（N 與出席率）要在簽署前填完，簽署後才定等於沒有停止條件。
- 簽署前確認：[IT 問卷](it-data-flow-questionnaire.md) 的「客戶決定」欄已填、[SOW](sow-template.md) 的範圍包含本頁。
