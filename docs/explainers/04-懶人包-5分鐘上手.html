1install
Clone + 互動式選 profile
把 repo 拉下來，跑 install.sh，會出現選單讓你挑哪個產業 — 不選硬湊，先試 core-only 也可以。
Terminal — bash
$ git clone https://github.com/jason-simhope-ai/manufacturing-skill.git $ cd manufacturing-skill && bash adapters/claude-code/install.sh ════════════════════════════════════════════════ manufacturing-skill installer · choose a profile ════════════════════════════════════════════════ 1) ✅ cnc-machining 2) 🚧 stub pcb-assembly 3) 🚧 stub injection-molding 4) 🚧 stub food-processing 5) 🚧 stub pharma 0) 🧪 (core-only, no profile) — try the framework first Default: cnc-machining (press Enter to accept) Select [0-5]: 0 → Installing core layer... → Skipping profile overlay (core-only mode) ✅ Installation complete.
2init
不知道下一步？打 /manufacturing init
第一次用打這個，AI 會問你 4 個問題（你做什麼、有沒有 ERP、資安要求、想看什麼），然後給你客製化下一步建議。
Claude Code
You ▸ /manufacturing init Claude ▸ 歡迎使用 manufacturing-skill！我問你 4 個問題搞定設定。 Q1. 你的工廠主要做什麼？ A) CNC 精密加工 B) PCB 組裝 C) 塑膠射出 D) 食品加工 E) 製藥 F) 多元化 / 想試框架 G) 其他（板金 / 紡織...） You ▸ F Claude ▸ Q2. 你有 ERP / MES 嗎？ A) 有 SAP / Oracle / 鼎新 B) 有但不在清單 C) 沒有 / Excel
3quote
第一個 /quote — 純文字描述也能報
不一定要圖紙。口頭描述 → AI 會問釐清問題，缺資料時不硬報，你補完它就算給結構化報價。
Claude Code
You ▸ /quote 「不鏽鋼 304 支架 50×30×10mm，4 個 φ6 通孔，量 100，要黑陽極」 Claude ▸ quote-specialist 接手報價。 觸發 pre-quote hook 檢查： ✅ 材料牌號明確（SUS304） ✅ 主要尺寸 + 公差有 ⚠️ 需澄清：「黑陽極」具體色號？（pantone / RAL / 自由色） ⚠️ 需澄清：交期需求？ 請補完上述兩項我就給結構化報價。[預估含稅 NT$40,000 ± 10%，視交期可能加 5% 急件費]
4order
查訂單狀態 — 一句話跨 6 段流程
不用打開 ERP 點 5 層選單。問「SO-XXX 在哪」AI 自動跨報價、接單、排程、生產、檢驗、出貨整合。
Claude Code
You ▸ /order-status SO-2026-0421 Claude ▸ sales-coordinator 訂單 SO-2026-0421（客戶A · 不鏽鋼支架 × 100） [3. 排程完成 → 4. 生產中] 進度 60% (60/100) 預計檢驗：2026-04-28 預計出貨：2026-04-30 ⚠️ 風險：刀具壽命將於第 80 件達上限 → 已通知刀具部，預計 4/26 14:30 換刀，不影響交期 📤 給客戶的回覆草稿： 「客戶您好，貴司訂單 SO-2026-0421 目前已生產 60 件， 預計 4/28 完成全部 100 件並進入品管檢驗，4/30 出貨。」
5inspect
品質檢驗 — IPQC 抽檢自動帶入 SPC
填量測值、AI 自動算 Cpk、對照 SPC 規則、發現失控立刻提醒，不用人工查表。
Claude Code
You ▸ /inspect IPQC W2026042100123 Claude ▸ quality-inspector W2026042100123 IPQC 巡檢（已加工 60 件，本次抽 5 件） 請填關鍵尺寸 φ20H7（規範 19.987~20.000）： You ▸ 19.992, 19.995, 19.991, 19.989, 19.987 Claude ▸ 量測值已記錄。 平均 X̄ = 19.991 R = 0.008 Cpk = 1.42（合格，> 1.33 標準） ✅ 全 5 件 OK，製程穩定 趨勢分析：X̄ 漸下移，距離 LCL 還有 4.2σ 安全 記錄已寫入 inspection record IPQC-20260426-007
6customize
客製給你的工廠 — fork CNC profile 改
CNC profile 是最完整範本。複製一份改成你的 vertical（食品 / PCB / ...）就能用。詳見 docs/profile-development.md。
Terminal — bash
$ cp -r profiles/cnc-machining profiles/my-injection-shop $ cd profiles/my-injection-shop # 改 3 個地方： $ vim profile.json # 改 name + agents 列表 $ vim agents/*.md # 改 prompt 對應你的工藝 $ vim know-how/*.md # 改 know-how 對應你的標準 $ cd ../.. && bash adapters/claude-code/install.sh my-injection-shop ✅ Installation complete. # 4 個 stub profile（PCB/射出/食品/製藥）內附 _starter-template.md，照著填更快

💰 預期花費
硬體？
不用買。先用雲端 Claude Code 跑（一台你現在的電腦就行）
月費？
Claude Code 訂閱（個人 ~ NT$600/月起）
什麼時候要地端硬體？
客戶會稽核 / 圖紙不可外流 → 才考慮買 GB10
❓ 常見問題
不是 CNC 廠也能用？
能。跑 install.sh --core-only 純試框架
資料會外流嗎？
.gitignore 排除真實圖紙；雲端用 Claude API（Anthropic 不訓練客戶資料）；地端 Ollama 完全不出網
壞了怎麼辦？
/manufacturing doctor 健檢，或 git pull 重裝
