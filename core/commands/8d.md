# /8d — 啟動 8D 處理流程

收到客訴或重大不良時打這個。AI 引導你走完 8D 八個步驟，產出可送客戶的報告。

## 使用範例

```
/8d                              # 互動式新建（AI 問 NCR 號 / 客戶 / 件號）
/8d NCR-2026-0421                # 對既有 NCR 走 8D
/8d 客戶A 不鏽鋼支架孔位超差     # 自由描述
```

## 流程

呼叫 **quality-inspector** 主導，dispatch：

- **production-planner** — 暫時對策（D3）的生產面影響
- **engineering-change-manager** — 永久對策（D5）若涉及設計變更
- **inventory-manager** — 隔離不良品庫存

執行 [`core/skills/8d-report-writing.md`](../skills/8d-report-writing.md) 的 8 步流程。

## 8 步驟簡介

| Step | 名稱                    | 主要產出                                           |
| ---- | ----------------------- | -------------------------------------------------- |
| D1   | 團隊組成                | Team list — 跨部門 3-7 人                          |
| D2   | 問題描述                | 5W2H + 量化（影響件數、客戶、金額）                |
| D3   | 暫時對策（Containment） | 隔離 + 100% 全檢 + 客戶端庫存控制                  |
| D4   | 根因分析                | 5 Why 或魚骨圖 → 直接根因 + 系統根因               |
| D5   | 永久對策                | 對應根因的具體措施（不只「強化教育訓練」這種廢話） |
| D6   | 對策實施 + 驗證         | 製程數據 / SPC 變化證明對策有效                    |
| D7   | 預防再發                | 更新 PFMEA / SOP / Control Plan / 防呆設計         |
| D8   | 結案 + 團隊感謝         | 客戶 sign-off + lessons learned 入庫               |

```

  8D Report — 8D-2026-0426-001
  W-...123 SUS304 支架孔距超差
═══════════════════════════════════════════════════

D1. Team
  Leader: 品管 張三
  Members: 生管 李四、CNC 工程師 王五、業助 陳六
  Customer Contact: 客戶 A 採購 林總

D2. Problem Description
  WHO: 客戶 A QC 收貨檢驗
  WHAT: 不鏽鋼支架（BR-12345）孔距 50.00±0.05 量得 50.08
  WHEN: 客戶 4/24 收件，4/25 反饋
  WHERE: 我廠 W-...123 工單第 80~100 件
  HOW MANY: 21 件超差（樣本 20 件中發現 1 件 → 整批 100% 複檢）
  IMPACT: 客戶停線 4 小時，金額損失估 NT$50,000

D3. Containment（暫時對策）
  ☑ 4/25 14:00 客戶端剩餘 79 件全部隔離
  ☑ 我廠在製品 50 件 100% 全檢，分出 8 件 NG（已隔離）
  ☑ 4/25 換刀 + 重設 CNC#3 程式 → 4/26 起新單均 OK

D4. Root Cause（根因分析）
  直接根因：D4 平銑刀第 80 件後磨耗 → 孔位偏移 0.03~0.08
  系統根因：刀具壽命管理 SOP 未明定 80 件強制換刀（依賴操作員經驗）

D5. Permanent Action（永久對策）
  1. 更新 SOP：D4 平銑刀加工 SUS304，每 80 件強制換刀（不論狀況）
  2. CNC#3 加裝刀具壽命計數器（採購中，預計 5/15 到位）
  3. PFMEA 更新：此工序的 D 分數從 6 → 4（加裝計數器後）

D6. Verification
  4/26 起 30 件 SPC 結果：孔距 X̄=49.998 R=0.012，Cpk=1.85（合格）
  附 SPC 控制圖 [chart-001.png]

D7. Prevent Recurrence
  ☑ SOP 更新版本 v2.3 已發行 4/27
  ☑ 同類所有 CNC 件刀具壽命表全面 review，3 件加嚴
  ☑ 操作員培訓 4/28 完成（簽到表附）

D8. Closure
  Customer sign-off: 客戶 A QC 林經理 4/30 簽認
  Lessons learned: 入庫 lessons/2026/2026-0426-tool-life.md
  Team thanks: 品管 / 生管 / CNC 工程師 / 業助 — 4/30 13:00 結案會議
```

## Anti-patterns

- ❌ D4 寫「操作員疏忽」就停 — 那不是根因，是表面。問下去「為什麼 SOP 沒擋住？」 → 找系統根因
- ❌ D5 寫「強化教育訓練」 — 教育訓練不是對策，是輔助；要有**結構性改變**（防呆 / SOP 強制 / 機制變更）
- ❌ D6 沒數據 — 「對策已實施」≠ 「對策有效」，要有 SPC / 後續抽檢數據
- ❌ D7 跳過 PFMEA 更新 — PFMEA 沒回去改，下次同類問題會再爆
