# 檢驗 Skill

製造業 6 段流程的第 5 段：**4 階段檢驗 + 不良處理**。

由 **quality-inspector** 主導。

---

## 4 個檢驗階段

| 階段 | 全名 | 時機 | 樣本 | 重點 |
|---|---|---|---|---|
| **IQC** | Incoming QC | 進料時 | AQL 1.5 / Level II | 規格、數量、COA / Mill cert |
| **IPQC** | In-Process QC | 製程中 | 巡檢 + SPC | 製程穩定、首件、巡檢 |
| **FQC** | Final QC | 完工後 | AQL 1.0 / Level II | 全尺寸、外觀、性能 |
| **OQC** | Outgoing QC | 出貨前 | 隨機 5% + 包裝 100% | 包裝、標籤、隨貨文件 |

---

## Process（每階段共用 5 步）

### 1. 載入檢驗 checklist

從 ERP 或 PLM 取對應件號的檢驗規範。如果 vertical 是 CNC 件，疊加 `profiles/cnc-machining/know-how/iatf-16949.md` 的 PPAP / FAI 要求。

### 2. 計算抽樣數

依 ANSI/ASQ Z1.4 (AQL 表)：

```
批量 100~150 件、AQL 1.5、Normal Level II → 樣本 n=20、Ac=1 / Re=2
意思：抽 20 件，最多允許 1 件不良；2 件不良就批退
```

### 3. 執行檢驗

每個檢驗項都記錄：

- 規範值 + 上下公差
- 量測值
- 量測工具（含校驗有效期）
- OK / NG
- NG 必填：偏差量、可能根因、處置（重工 / 報廢 / 特採）

### 4. 判定與記錄

```
判定規則：
  - NG 數 ≤ Ac → 合格
  - Ac < NG 數 < Re → 加嚴抽樣（再抽一倍）
  - NG 數 ≥ Re → 整批不合格
```

合格 → 觸發下一段（FQC 通過 → OQC、OQC 通過 → 出貨）
不合格 → 進入 **不良品處理**

### 5. 不良品處理（NCR + 8D）

- 開立 NCR (Non-Conformance Report)
- 隔離不良品
- 啟動 8D：
  - D1 團隊組成
  - D2 問題描述
  - D3 暫時對策
  - D4 根因分析（5 Why / Fishbone）
  - D5 永久對策
  - D6 對策實施
  - D7 預防再發
  - D8 結案

---

## Checklist（FQC 範例）

- [ ] 抽樣數依 AQL 計算正確
- [ ] 每個檢驗項都有量測工具紀錄
- [ ] 量測工具校驗未過期
- [ ] NG 件已 100% 隔離
- [ ] NG 根因已找到
- [ ] NCR / 8D 已開立（如需要）
- [ ] inspection record 已存檔（traceability）

---

## Anti-patterns

- ❌ 「目視合格」當數據 → 一律量測
- ❌ 沒填根因放行 → 未來客訴找不到原因
- ❌ 為了趕交期縮樣本 → 風險溝通給生管，不私下決定
- ❌ NG 件混回良品堆 → 災難
- ❌ 8D 寫好看的、沒落實 → 同一問題會再發
