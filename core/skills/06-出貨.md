# 出貨 Skill

製造業 6 段流程的第 6 段（最後）：**從 OQC 通過到客戶簽收**。

由 **sales-coordinator** 主導，**inventory-manager** 配合包裝出貨。

---

## Process（5 步）

### 1. OQC 通過確認

- 檢查 OQC 報告（樣本通過、包裝合格、文件齊全）
- 觸發 `core/hooks/pre-ship.md`：再次確認所有文件齊全

### 2. 包裝

依客戶包裝規範（如有）：

- 內包裝（防銹油、塑膠袋、抽真空？）
- 外箱規格（紙箱 / 木箱 / 棧板）
- 標籤（料號、批號、數量、製造日期、客戶 PO）
- 隨貨文件（出貨單、COA、檢驗報告、TLC、Mill cert）

### 3. 隨貨文件準備

| 文件 | 必備 | 客製依需求 |
|---|---|---|
| 出貨單（Packing List） | ✅ | |
| 商業發票 | ✅ | |
| COA（Certificate of Analysis） | 視客戶 | ✅ 食品 / 製藥 / 化工 |
| 檢驗報告（FQC + OQC） | 視客戶 | ✅ IATF 16949 客戶 |
| Mill Cert（材料證明） | 視客戶 | ✅ 結構件 / 安全件 |
| 海關文件（Form A、CO） | 出口時 | ✅ |
| MSDS（化學品） | 化學品時 | ✅ |

### 4. 安排運輸

- 國內：物流公司 / 自送
- 國外：海運 / 空運 / 快遞
- INCOTERMS 確認（EXW / FOB / CIF / DDP）
- 預約時間 + 司機聯絡

### 5. 出貨後通知與追蹤

- 通知客戶：出貨單 + 追蹤號 + 預計到貨日
- 建立追蹤紀錄到 ERP
- 等客戶簽收回執
- 更新 `scheduler-mcp` 把這張 SO 標 closed

---

## Checklist

- [ ] OQC 已通過、報告已附
- [ ] 包裝符合客戶規範
- [ ] 標籤資訊完整且正確
- [ ] 所有隨貨文件齊全
- [ ] 運輸方式 + INCOTERMS 確認
- [ ] 客戶已收到出貨通知
- [ ] ERP 已更新出貨紀錄

---

## Anti-patterns

- ❌ OQC 沒過硬出 → 客戶退貨 + 信任崩
- ❌ 標籤亂貼 → 客戶倉庫上架錯亂
- ❌ 漏隨貨文件 → 客戶倉庫拒收
- ❌ INCOTERMS 沒確認 → 運費歸屬糾紛
- ❌ 出貨不通知 → 客戶以為延誤 → 客訴
