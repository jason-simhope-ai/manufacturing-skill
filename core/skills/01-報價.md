# 報價 Skill

製造業 6 段流程的第 1 段：**從詢價到報出價的完整流程**。

由 **quote-specialist** agent 主導，必要時 dispatch 給 vertical profile 的專精 agent（如 `cnc-programmer`）協助技術評估。

---

## Process（6 步）

### 1. 接收與分類

- 解析 input：圖紙 / BOM / RFQ 文件 / 口頭描述
- 分類：標準件報價（重複客戶 + 既有規格）vs 開發件報價（新規格 / 首樣）
- 分類影響：開發件多加 prototype 工時 + 風險加成

### 2. 圖紙完整度檢查（pre-quote hook）

觸發 `core/hooks/pre-quote.md`，檢查：

- [ ] 公差完整（關鍵尺寸都有公差）
- [ ] 表面粗糙度標註
- [ ] 材料牌號明確
- [ ] 表面處理規範（電鍍 / 陽極 / 噴塗厚度）
- [ ] 熱處理要求（如硬度範圍）
- [ ] 數量、交期、付款條件

**任何一項缺，停下來問，不要硬報**。

### 3. 工藝路線設計

依工件特徵展開製程：

```
範例：不鏽鋼 304 支架 50×30×10mm，孔 φ6 通孔 × 4
工序：
  OP10 下料（鋸切）       — 機台：帶鋸 / 工時 2min
  OP20 銑外形 + 鑽孔       — 機台：CNC 銑床 / 工時 8min
  OP30 去毛刺              — 人工 / 工時 1min
  OP40 陽極氧化（外包）    — 外包單價 NT$5/件
  OP50 FQC                 — 抽檢 AQL 1.5
```

對於 CNC 件，dispatch `cnc-programmer` 確認：
- 是否需要客製夾治具
- G-code 編程工時
- 切削參數估算（用 `profiles/cnc-machining/skills/cutting-parameter-calc.md`）

### 4. 成本計算

```
材料成本 = 單價 × (用量 × (1 + 損耗率%))
  - 損耗率參考：金屬 5-10%、塑膠 3-5%、貴金屬 1-3%

加工成本 = Σ (工時 × 機台費率)
  - 機台費率含：人工 + 機台折舊 + 水電 + 管理費分攤
  - 從 erp-connector 取最新費率

外包成本 = Σ (外包報價 × (1 + 管理費率%))
  - 管理費率：5-10%

總製造成本 = 材料 + 加工 + 外包
```

### 5. 利潤與風險加成

```
標準利潤率 = 客戶分級表 × 數量級距 × 付款條件
  - 客戶分級從 erp-connector 取得（A/B/C 分級）
  - 量大利潤低，量小利潤高

風險加成（明列）：
  - 首件 / 開發件：+10~15%
  - 急件（< 標準 lead time 50%）：+10%
  - 特殊規格（非標準件）：+5~10%
  - 客戶歷史付款不良：+5%（私下加，不寫在報價）

最終報價 = 總製造成本 × (1 + 利潤率 + 風險加成)
```

### 6. 輸出報價單

格式：`examples/sample-quote-output.md`，必含：

- Quote ID（Q-YYYYMMDD-NNN）
- 客戶 / 件名 / 規格 / 數量
- 成本明細（材料 / 加工 / 外包，全展開）
- 利潤與風險加成（明列 %）
- 報價金額（含稅 / 未稅 / 幣別）
- 預估交期（基於 scheduler-mcp 查當前產能）
- 假設與備註（[ASSUMED] 標籤）
- 需澄清項目（[需澄清] 標籤）
- 有效期（預設 30 天）

---

## Checklist

完成報價前確認：

- [ ] pre-quote hook 通過（所有圖紙資料齊全）
- [ ] 工藝路線涵蓋所有工序（沒漏 OP）
- [ ] 材料成本基於最近採購單價（< 30 天）
- [ ] 機台費率為最新版本
- [ ] 利潤率對應客戶分級
- [ ] 風險加成明列、有理由
- [ ] 預估交期已查 scheduler-mcp 產能
- [ ] 所有假設條件已 [ASSUMED] 標明
- [ ] 所有不確定處已 [需澄清] 標明
- [ ] Quote ID 已分配、可追溯

---

## Anti-patterns（不要做的事）

- ❌ 圖紙不完整就硬報 → 風險全在自己身上
- ❌ 用上一單的價直接報這一單 → 規格、量、付款條件可能不同
- ❌ 把風險藏在毛利裡 → 事後檢討找不到原因
- ❌ 沒查產能就承諾交期 → 會 over-promise
- ❌ Quote ID 跳號或重複 → 無法追溯
