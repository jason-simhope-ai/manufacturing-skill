# 接單 Skill

製造業 6 段流程的第 2 段：**從客戶 PO 到內部工單的完整流程**。

由 **sales-coordinator** 主導，必要時 dispatch 給 **production-planner** 預排產能、**inventory-manager** 預檢料況。

---

## Process（5 步）

### 1. PO 與 Quote 對帳

收到客戶 PO 後，第一件事是把 PO **逐項比對 Quote**：

| 比對項 | 規則 |
|---|---|
| 件號 / 規格 | 必須完全一致 |
| 數量 | 允許 ±0% (或合約定義的允收差) |
| 單價 | 必須一致；不一致時看是否在 quote 有效期內 |
| 交期 | PO 要的交期 vs Quote 承諾交期 |
| 付款條件 | T/T 30 / 月結 60 等 |
| 包裝 / 運送 | EXW / FOB / DDP |

**任何差異** → 產出 `contract_diff_report` → 業務經理裁示。

### 2. 信用查核

- 客戶信用額度（從 erp-connector 取）
- 已開未收金額 + 本單金額是否超額
- 付款歷史（是否有遲付、跳票）

超額 → 業務 + 財務裁示，是否縮短付款條件 / 收頭款 / 拒接。

### 3. 開立 Sales Order（SO）

ERP 系統開單，必填：

- SO ID（SO-YYYY-NNNN）
- 客戶 / 件號 / 規格 / 數量 / 單價
- 客戶交期 / 內部承諾交期（含緩衝）
- 付款條件 / 包裝運送
- 連結的 Quote ID
- 附件：客戶 PO 原檔、簽核紀錄

### 4. 觸發 post-order hook

`core/hooks/post-order.md`：

- 通知 **production-planner** 排程
- 通知 **inventory-manager** 預檢料況（是否需立刻採購）
- 通知客戶「PO 已收，預計開工日 X」

### 5. 產生工單（Work Order, WO）

由 production-planner 接手後做：

- 一張 SO 可拆多張 WO（依工序、批次）
- WO ID（W-YYYYMMDD-NNNNN）
- 連結回 SO
- 派工資訊：機台、人員、預計開工 / 完工日

---

## Checklist

- [ ] PO vs Quote 逐項對帳完成
- [ ] 任何差異都已產出 contract_diff_report 並裁示
- [ ] 客戶信用額度已查
- [ ] SO 已建立，所有欄位填寫完整
- [ ] post-order hook 已觸發
- [ ] WO 已產出，已派工
- [ ] 客戶已收到「PO 已收」確認

---

## Anti-patterns

- ❌ PO 跟 Quote 不一致直接吃單 → 後續責任歸屬不清
- ❌ 不查信用就開單 → 收款風險
- ❌ SO 沒連回 Quote → 追溯斷掉
- ❌ 開了 SO 不告訴生管 → 排程亂
