# 排程 Skill

製造業 6 段流程的第 3 段：**從工單到實際派到機台與人員**。

由 **production-planner** 主導。

---

## Process（4 步）

### 1. 載入待排工單與現況

從 `scheduler-mcp` 取：

- 待排工單清單（含工序、預估工時、客戶交期）
- 各機台目前負載與排程
- 人員班表與技能矩陣
- 已知異常（機台保養、員工請假、缺料）

### 2. 派工順序決策

優先級規則（由高到低）：

1. **客戶承諾急件**（業務標記 + 主管核可）
2. **長 lead time 卡瓶頸件**（提早開，避免最後塞車）
3. **同夾治具批次合併**（節省 setup time）
4. **短工時優先**（縮短平均交期，提升 OEE）
5. **新進單先到先做**（FIFO）

### 3. 機台與人員配置

- 機台：選**負載低、能力符合**的機台；避開負載 > 85% 的瓶頸機
- 人員：依技能矩陣選有對應機台 / 工序資格的
- Setup：同夾治具盡量連排，減少換型
- 緩衝：每張單預留 15-20% 緩衝給意外

### 4. 完工日預估與回報

```
完工日 = 開工日 + Σ(工序工時 + setup) × (1 + 緩衝率) / 班別工時
```

如果預估 > 客戶交期 → 立刻通知 sales-coordinator 與業務主管：
- 是否需外包補產能
- 是否需溝通延期
- 是否需加班 / 三班

---

## 瓶頸識別

每天早上跑一次 bottleneck scan：

```
For each machine:
  load_pct = scheduled_hours_next_7d / available_hours_next_7d
  if load_pct > 0.85:
    flag as bottleneck
    suggest: 外包 / 新增班別 / 改派其他機台
```

---

## Checklist

- [ ] 待排工單已從 scheduler-mcp 取得
- [ ] 機台負載已計算
- [ ] 派工順序符合優先級規則
- [ ] 每張工單都有完工日預估
- [ ] 預估 > 客戶交期的工單已標示風險
- [ ] 瓶頸機已識別並提建議
- [ ] 排程結果已回寫 scheduler-mcp

---

## Anti-patterns

- ❌ 排到 100% 滿載 → 第一個意外就崩
- ❌ 不算 setup time → 預估全錯
- ❌ 派沒培訓的人到關鍵機台 → 品質風險
- ❌ 急件插隊不通知原本工單客戶 → 後面客戶被坑
