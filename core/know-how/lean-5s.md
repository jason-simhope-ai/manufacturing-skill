# Lean / 5S 精實生產與現場管理

製造業現場效率的兩大基本功。

---

## 5S 現場管理

| S   | 日文            | 中文 | 內容                       |
| --- | --------------- | ---- | -------------------------- |
| 1   | 整理 (Seiri)    | 整理 | 區分要與不要，丟掉不要的   |
| 2   | 整頓 (Seiton)   | 整頓 | 要的東西定位、定量、定容器 |
| 3   | 清掃 (Seiso)    | 清掃 | 每天清，並在清掃中發現異常 |
| 4   | 清潔 (Seiketsu) | 清潔 | 把 1-3 標準化、規範化      |
| 5   | 素養 (Shitsuke) | 素養 | 養成習慣，自發遵守         |

**為什麼 agent 要懂**：

- 排程時要排「同夾治具批次」減少找東西時間
- 異常分析時，「找不到工具」是常見根因
- 現場稽核分數低的工廠通常品質也差

## 7 大浪費（Muda）

Lean 識別的 7 種浪費：

| #   | 浪費     | 例子                    | agent 該怎麼想       |
| --- | -------- | ----------------------- | -------------------- |
| 1   | 過量生產 | 客戶要 100 做 150       | 排程嚴格按 SO 數量   |
| 2   | 等待     | 機台等料、等夾具        | 缺料預警提前         |
| 3   | 搬運     | 件在工廠繞來繞去        | 工序順序設計時減動線 |
| 4   | 過度加工 | 客戶要 Ra3.2 做到 Ra1.6 | 對著規範做，不過度   |
| 5   | 庫存     | 半成品堆積              | WIP 控管             |
| 6   | 動作     | 操作員伸手太遠          | 5S 整頓              |
| 7   | 不良     | 重做 / 報廢             | SPC + 首件 + IPQC    |

（後人加第 8 種：未善用的人才創意）

## JIT (Just In Time)

「在需要的時候、做需要的量、給需要的客戶」。

對 agent 的影響：

- 安全庫存設置：不能太多（庫存浪費）也不能太少（缺料風險）
- 看板（Kanban）：拉式生產，下游拉動上游
- 平準化（Heijunka）：把波動大的訂單均勻化

---

## Kaizen 持續改善

每天小改善 > 偶爾大革新。

agent 在每次 `/inspect` 不良、`/order-status` 延誤後，**主動建議一個小改善**（即使只是「下次先檢查 X」）。

---

## 對 agent 的硬要求

- 排程時優先合併同夾治具批次（減 setup time）
- 任何「找不到 X」「等 Y」「重做 Z」都要記錄並追蹤
- 改善建議要小、要具體、要可立刻試（不要「我們需要文化變革」）

---

## 常見誤解

- ❌ 5S 只是打掃 → 5S 是現場管理體系
- ❌ Lean 是裁員工具 → Lean 是消除浪費，人員應改去做更高價值
- ❌ 庫存越少越好 → 安全庫存太低 = 缺料風險
