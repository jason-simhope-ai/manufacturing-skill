# INCOTERMS 2020 國際貿易條款

> 此文件用 **INCOTERMS 2020**（ICC, 自 2020-01-01 起生效）。
> 老合約可能還在用 **INCOTERMS 2010** — 兩者**不能混用**，合約上要明寫年份。
> 最有名的差異：2010 的 DAT (Delivered At Terminal) 在 2020 改名 DPU (Delivered at Place Unloaded)。

---

## 一句話定義

INCOTERMS = **賣方 vs 買方** 在「**運輸成本**、**運輸風險**、**進出口手續**」三件事上各負責到哪。

避免「我以為你會付運費，你以為我會付」這種糾紛 → 合約寫 INCOTERMS 就解決。

---

## 11 個條款（按賣方責任由小到大排）

### 適用任何運輸方式（7 個）

| 縮寫    | 全名                           | 中文            | 賣方責任到                                     |
| ------- | ------------------------------ | --------------- | ---------------------------------------------- |
| **EXW** | Ex Works                       | 工廠交貨        | 工廠門口（買方自取）                           |
| **FCA** | Free Carrier                   | 貨交運送人      | 賣方指定地點（通常是出口港或機場），交給運送人 |
| **CPT** | Carriage Paid To               | 運費付訖        | 賣方付運費，但風險在貨交給第一運送人時轉給買方 |
| **CIP** | Carriage and Insurance Paid To | 運費 + 保險付訖 | 同 CPT 但加保險                                |
| **DAP** | Delivered at Place             | 目的地交貨      | 買方指定地點（未卸貨）                         |
| **DPU** | Delivered at Place Unloaded    | 目的地卸貨交貨  | 買方指定地點（**已卸貨**） — 2020 從 DAT 改名  |
| **DDP** | Delivered Duty Paid            | 完稅後交貨      | 買方指定地點 + 卸貨 + 進口報關 + 關稅          |

### 只適用海運 / 內河運輸（4 個）

| 縮寫    | 全名                        | 中文             | 賣方責任到                               |
| ------- | --------------------------- | ---------------- | ---------------------------------------- |
| **FAS** | Free Alongside Ship         | 船邊交貨         | 出口港，貨放船邊                         |
| **FOB** | Free on Board               | 船上交貨         | 出口港，貨**裝上船**                     |
| **CFR** | Cost and Freight            | 成本加運費       | 賣方付海運費，但風險在貨裝上船時轉給買方 |
| **CIF** | Cost, Insurance and Freight | 成本、保險、運費 | 同 CFR 但加保險                          |

> ⚠️ **別把 FOB 用在貨櫃運輸** — 貨櫃是在貨櫃場交給運送人（不是船上）。貨櫃應該用 FCA。許多舊合約還在誤用 FOB，2020 INCOTERMS 也再次強調這點。

## 風險轉移點 + 成本承擔點 對照

```
                   風險轉移點         成本承擔點 (運費 + 保險)
EXW                工廠門口            買方全包
FCA                指定點交運送人      買方包後續
FOB                船上 (海運)         買方包後續
CFR                船上                賣方包到目的港，買方包卸貨後
CIF                船上                賣方包到目的港 + 保險，買方包卸貨後
CPT                第一運送人          賣方包到目的地
CIP                第一運送人          賣方包到目的地 + 保險
DAP                目的地              賣方包全部（未卸貨）
DPU                目的地卸貨後        賣方包全部（含卸貨）
DDP                目的地              賣方包全部（含關稅）
```

**關鍵觀察**：CFR / CIF / CPT / CIP — **付錢的人 ≠ 承擔風險的人**。賣方付到目的地的運費，但貨在裝船/交運送人後就由買方承擔風險。這是新手最常踩的雷。

## 進出口報關責任

| 條款                          | 出口報關 | 進口報關 |
| ----------------------------- | -------- | -------- |
| EXW                           | **買方** | 買方     |
| 其餘 9 個（FCA 起到 DAP/DPU） | 賣方     | 買方     |
| **DDP**                       | 賣方     | **賣方** |

> 賣方出 EXW = 連出口都不管 → 多數實務不可行（買方無法在賣方國家報關）。
> 賣方出 DDP = 連進口都包 → 賣方要熟買方國家的稅務，風險高，不建議除非極熟悉的市場。

## 製造業最常用的 5 個

| 場景                     | 推薦條款                | 理由                             |
| ------------------------ | ----------------------- | -------------------------------- |
| 國內客戶，自取           | EXW                     | 簡單                             |
| 國內客戶，公司送         | DDP（國內無關稅）或 DAP | 客戶不操心                       |
| 國外客戶，海運貨櫃       | **FCA**（不是 FOB！）   | 風險清楚                         |
| 國外客戶，賣方包到目的港 | **CIF**                 | 老牌標準，買賣雙方都熟           |
| 國外客戶，老美客戶要求   | DDP（多）               | 美國買家通常希望「全包到我倉庫」 |

## 對 agent 的影響

- **`quote-specialist`**：報價時必明寫 INCOTERMS 條款 → 客戶 RFQ 沒寫，主動問 → 不同條款價差很大（DDP vs EXW 可能差 10-30%，特別是運費高的線路）
- **`sales-coordinator`**：客戶問「為什麼這次貴」可能是 INCOTERMS 變了 → 合約上的條款要當「鎖價」依據之一
- **`production-planner`**：DDP 訂單要算進口清關時間（通常 + 3-7 天），不能跟 EXW 同預估交期
- **6 段流程的 06-出貨**：包裝規格 + 隨貨文件依 INCOTERMS 不同 — DDP 需要進口國的文件、CIF 需要保險證明

## 常見誤解

- ❌ **「FOB 就是船上」 → 適用海運貨櫃** — 海運**散貨** OK，貨櫃應用 FCA
- ❌ **「CIF 包保險就萬無一失」** — INCOTERMS 規定的最低保險覆蓋率（ICC C 條款）很基本，敏感件應自加保
- ❌ **「合約寫 FOB 就好」** — 必須加 **「FOB Kaohsiung Port, INCOTERMS 2020」** — 缺地點或年份就可能糾紛
- ❌ **「DDP 對賣方最划算（價最高）」** — 通常**最虧** — 進口稅務不熟、目的國 VAT 退不回來、有海關預扣風險
- ❌ **「INCOTERMS 規範付款條件」** — **不**規範。付款條件（T/T、L/C、月結）是另一個合約條款

## 速查口訣

```
E 開頭 = 賣方責任最少（EXW）
F 開頭 = 賣方包到「F」reight starts（FCA / FAS / FOB）
C 開頭 = 賣方付「C」osts but no risk（CPT / CIP / CFR / CIF）
D 開頭 = 賣方包到「D」estination（DAP / DPU / DDP）
```
