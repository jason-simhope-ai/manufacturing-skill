# ISO 9001 品質管理體系基礎

> 國際通用的品質管理體系標準。製造業 95% 的客戶要求供應商有 ISO 9001 證書。
> 本文是 agent 操作參考用的精華版，不取代官方標準。

---

## 7 大品質管理原則

| #   | 原則     | 對 agent 的意義                              |
| --- | -------- | -------------------------------------------- |
| 1   | 顧客導向 | 報價、出貨永遠以客戶要的為準，不是我們方便的 |
| 2   | 領導作用 | 高層的政策落實到每張工單                     |
| 3   | 全員參與 | 操作員的回饋是改善來源                       |
| 4   | 過程方法 | 每個流程定義清楚的 input/output/責任         |
| 5   | 改善     | 每次客訴 / 不良都是改善機會                  |
| 6   | 證據決策 | 用數據（SPC、檢驗報告）做決定                |
| 7   | 關係管理 | 供應商也要管，IQC 退貨要追根因               |

## 文件層級（金字塔）

```
        ┌─────────────┐
        │ 品質手冊    │  ← 最上層，公司品質政策
        ├─────────────┤
        │ 程序書      │  ← 各部門怎麼做事
        ├─────────────┤
        │ 作業指導書  │  ← 具體某動作的 SOP
        ├─────────────┤
        │ 紀錄表單    │  ← 執行的證據（檢驗報告、出貨單...）
        └─────────────┘
```

agent 產出的所有 record 都要**可追溯到**對應的程序書 / 作業指導書。

## PDCA 循環

每個品質活動都套這個：

- **Plan** — 定目標、規劃
- **Do** — 執行
- **Check** — 量測結果
- **Act** — 不符合標準 → 改善 → 回到 Plan

8D 報告本質就是 PDCA 的具體化。

---

## 客戶稽核常見要求

agent 在報價、生產、出貨時要記住，這些客戶稽核會看：

- 完整的 inspection record（含量測工具校驗證明）
- 物料追溯（料號 → 批號 → 工單 → 客戶 PO）
- 不良品處理紀錄（NCR、8D）
- 變更管理紀錄（圖紙改版、製程變更）
- 供應商評鑑紀錄
- 人員培訓紀錄
- 校驗紀錄（量測工具、機台精度）

---

## 對 agent 的硬要求

- 每次 `/inspect` 都要產生**可追溯的 inspection record**
- 每次 NG 都要**有根因 + 對策**
- 每次「特採」（concession）都要**客戶書面同意**
- 每次圖紙 / BOM 改版都要**走變更管理流程**

---

## 常見誤解

- ❌「ISO 9001 是寫文件給稽核員看的」→ 文件沒落實 = 廢紙
- ❌「我們小公司不用」→ 客戶會要
- ❌「過了證 = 品質好」→ 證只代表體系存在，品質還是看每天執行
