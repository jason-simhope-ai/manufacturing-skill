# IATF 16949 汽車品質管理體系 / PPAP

> 汽車產業客戶（OEM、Tier 1、Tier 2）普遍要求的品質體系，適用任何汽車供應商製程：機械加工、射出、壓鑄、鈑金沖壓、電子組裝。
> 此文件講「體系 + PPAP 流程」的共通骨架；各製程的落地差異見文末〈各製程的差異〉。
>
> **重要**：IATF 16949 與 PPAP 都留了很大空間給**客戶特定要求（CSR, Customer-Specific Requirements）**。本文的數字（等級、Cpk 門檻、樣本數）是手冊的通用值，**實際以客戶 CSR / 採購合約 / 客戶的 SQA 手冊為準**。本文**不是**稽核員意見，量產前請由持證稽核員或客戶 SQE 覆核。

---

## 與 ISO 9001 的關係

```
IATF 16949:2016 = ISO 9001:2015 + 汽車產業特定要求（+ 客戶 CSR）
```

- IATF 16949 以 ISO 9001 為基礎、**不是獨立標準** — 兩者要一起讀、一起落實。
- 是否「拿 IATF 證就自動含 ISO 9001 證」取決於驗證機構與 IATF 認證規則，不要在對外文件裡直接宣稱（需驗證）。
- 汽車件的要求通常比一般 ISO 9001 嚴格（例如必須有 Control Plan、MSA、特殊特性管理、PPAP），但**ISO 9001 本身並沒有規定 Cpk 門檻**；Cpk 門檻來自 PPAP / 客戶 CSR（見下文）。

## 5 個核心工具（Core Tools）

| 工具     | 全名                              | 用途                          |
| -------- | --------------------------------- | ----------------------------- |
| **APQP** | Advanced Product Quality Planning | 產品開發階段品質規劃          |
| **PPAP** | Production Part Approval Process  | 量產件批准（送樣 + 文件）     |
| **FMEA** | Failure Mode and Effects Analysis | 失效模式分析（DFMEA + PFMEA），見 [fmea-pfmea](fmea-pfmea.md) |
| **MSA**  | Measurement System Analysis       | 量測系統分析（GR&R）          |
| **SPC**  | Statistical Process Control       | 統計製程管制，見 [spc-basics](../skills/spc-basics.md) |

> 對應的 IATF 16949:2016 條款（作者記憶，需對照標準原文）：產品核准流程 §8.3.4.4（PPAP）、特殊特性 §8.3.3.3、管制計畫 §8.5.1.1、量測系統分析 §7.1.5.1.1。

> 另一個常被併提的是 **Control Plan（管制計畫）**（§8.5.1.1），它把 PFMEA 的結論轉成現場的檢驗/管制動作，是 PPAP 的核心文件之一。
> 德系客戶可能要求 **VDA 6.3 / VDA 2 (PPA)** 而不是（或加上）AIAG PPAP — 以客戶要求為準。

## PPAP 提交等級（5 級）

PPAP 手冊定義 5 個提交等級，差別在「**交什麼給客戶**」，不是「做不做」— 18 項要素的證據不論哪一級，供應商都要備齊並保存。

| Level | 提交給客戶的內容                                         | 備註                                       |
| ----- | -------------------------------------------------------- | ------------------------------------------ |
| 1     | **僅 PSW**（指定外觀件另加 AAR）                         | 其餘文件供應商自存                         |
| 2     | PSW + **產品樣品** + **有限**佐證資料                    | 哪些資料屬「有限」依客戶指定               |
| 3     | PSW + 產品樣品 + **完整**佐證資料                        | **預設等級**（客戶未另行指定時）           |
| 4     | PSW + 客戶另行規定的其他項目                             | 內容完全由客戶決定                         |
| 5     | PSW + 樣品 + 完整佐證資料，**在供應商製造現場供客戶審查** | 客戶到廠審查，不是「內部審核」             |

- 最常用：**Level 3**（客戶未指定即為 Level 3）。實務上客戶會在採購合約或 SQA 手冊指定每個件號的等級。
- 每份要素「提交（S）」還是「保存備查（R）」的對照表（例如 Master Sample、Checking Aids 在 Level 3 為保存而非提交），請對照 PPAP 手冊原文的提交/保存要求表（需驗證逐項 S/R）。
- PPAP 結果有 3 種：**核准（Approved）**、**暫時核准（Interim Approval，有期限/數量限制）**、**拒絕（Rejected）**。

### PPAP 18 項要素

下表為 AIAG PPAP 4th Edition 的 18 項要素（項次與名稱以手冊為準）：

| #  | 要素（英文）                                       | 中文 / 說明                                                  |
| -- | -------------------------------------------------- | ------------------------------------------------------------ |
| 1  | Design Records                                     | 設計紀錄（可銷售產品的圖紙，含氣球標註圖 ballooned drawing） |
| 2  | Authorized Engineering Change Documents            | 已授權的工程變更文件（ECN / ECR 等，見 [eco-ecn](eco-ecn.md)） |
| 3  | Customer Engineering Approval                      | 客戶工程核准（若客戶要求）                                   |
| 4  | Design FMEA                                        | DFMEA（供應商有設計責任時）                                  |
| 5  | Process Flow Diagram                               | 製程流程圖                                                   |
| 6  | Process FMEA                                       | PFMEA（見 [fmea-pfmea](fmea-pfmea.md)）                      |
| 7  | Control Plan                                       | 管制計畫                                                     |
| 8  | Measurement System Analysis Studies                | 量測系統分析（GR&R、偏差、線性、穩定性等）                   |
| 9  | Dimensional Results                                | 尺寸量測結果（每個圖面特性、每個模穴/工位；俗稱「首件全尺寸 FAI」，見下） |
| 10 | Records of Material / Performance Test Results     | 材料與性能試驗紀錄                                           |
| 11 | Initial Process Studies                            | 初期製程研究（特殊特性的 SPC / 製程能力）                    |
| 12 | Qualified Laboratory Documentation                 | 合格實驗室文件（實驗室範圍、認證）                           |
| 13 | Appearance Approval Report (AAR)                   | 外觀核准報告（僅外觀件）                                     |
| 14 | Sample Production Parts                            | 樣品（量產件）                                               |
| 15 | Master Sample                                      | 標準樣品（供應商保存、經客戶簽核）                           |
| 16 | Checking Aids                                      | 檢具 / 治具（含校驗紀錄與尺寸驗證）                          |
| 17 | Records of Compliance with Customer-Specific Requirements | 客戶特定要求符合性紀錄（含 IMDS / 材料申報等，依客戶）  |
| 18 | Part Submission Warrant (PSW)                      | 零件提交保證書 — 供應商簽署的封面，聲明全部要求已符合        |

### PPAP 何時要（重新）提交

「PPAP 給一次就好」是常見誤解。依 PPAP 手冊與客戶 CSR，下列情況通常需通知客戶並重新提交（完整清單以手冊提交時機章節與客戶 CSR 為準）：

- 新件、新版圖紙（設計變更）
- 製程、設備、工模具的重大變更（轉移、更換、整修、新增）
- 材料或次階供應商（sub-supplier）變更
- 生產地點變更
- 工模具閒置一段時間後恢復量產（手冊常見表述為 12 個月，需驗證；客戶 CSR 可能更嚴）
- 客戶要求的其他情況（如不良/客訴後的矯正行動）

## Dimensional Results 與 FAI（首件全尺寸）

PPAP 第 9 項是「尺寸量測結果」：對圖面上**每一個**要求特性（尺寸、公差、粗糙度、形位公差）都要實測並記錄，**多穴模 / 多工位 / 多夾具要每個穴位各量**。

> 「FAI（First Article Inspection）」在汽車業常被當成 Dimensional Results 的口語說法；正式的 FAI 格式（例如航太的 AS9102）是另一套規範，**汽車客戶要什麼格式以客戶 CSR 為準**。

```
Dimensional Results（範例格式）
件號：BR-12345 rev2
工單：W2026042100123
穴位 / 工位：Cavity 3 / OP20
量測日期：2026-04-21
量測員：張三
量測工具：CMM ABC-001（校驗有效期 2026-12）

| Item | 規範 | 實測 | 偏差 | OK/NG |
| 1    | 50.00 ± 0.05  | 50.012 | +0.012 | OK |
| 2    | φ20H7 | φ19.992 | -0.008 | OK |
...
```

## 初期製程研究、Cpk / Ppk 與 Run @ Rate

### 初期製程研究（PPAP 第 11 項）

- 對客戶 / 供應商指定的**特殊特性**做 SPC 研究；先確認製程**穩定**（管制圖無失控），再看能力指數。
- PPAP 手冊對初期研究的一般判讀（客戶 CSR 可另訂）：

| 指數      | 判讀                                         |
| --------- | -------------------------------------------- |
| > 1.67    | 製程目前符合客戶要求                         |
| 1.33–1.67 | 可接受，但可能需要改善、與客戶確認           |
| < 1.33    | 不符合接受準則；需矯正行動與客戶同意如何處理 |

- **1.67 / 1.33 是 PPAP 初期研究的通用判讀，不是 IATF 16949 條文，也不是 ISO 9001 的要求。**客戶可能要求不同門檻（如 Cpk ≥ 1.33 或 ≥ 1.67、或另以 Ppk 表示）；初期（短期）研究常用 Ppk，量產（長期穩定）用 Cpk — 用哪個指數、樣本數多少以客戶 CSR 為準（需驗證）。
- 初期研究的取樣條件：來自「**有意義的量產批（significant production run）**」，手冊的通用說法是至少 300 件連續產出（或客戶同意的其他數量）— 以手冊原文與客戶要求為準（需驗證）。

### Run @ Rate（量產節拍驗證）

在量產條件（量產模/治具、量產人員、量產節拍）下連續生產，證明製程能在**客戶要求的節拍**下穩定達成良率與品質。常見由客戶 CSR / APQP 要求，**不是 PPAP 18 項之一**；時間長度與數量由客戶指定（常見說法是 300 件 / 數小時，但無通用標準值，需驗證）。

## 對 agent 的硬要求

當客戶為汽車業時：

- `quote-specialist` 要把 PPAP 文件成本（量測、實驗室、樣品、檢具、客戶審查陪同）算進報價
- 開發階段的 dispatch（若 profile 有 `prototype-coordinator` 之類角色）要走 APQP / PPAP 流程，不可只當一般試作
- `quality-inspector` 用汽車嚴格版檢驗：特殊特性依 Control Plan、FAI/Dimensional Results 每穴位全尺寸、MSA 有效才算數
- 所有 record 要可追溯到 SO + WO + 操作員 + 機台 / 模具 / 工位 + 材料批號（各製程的追溯單位見下節）
- PPAP 所需門檻值（Cpk、樣本數、等級）**先問客戶 CSR**，不要用本文數字當承諾

## 各製程的差異

PPAP 18 項要素與提交等級對所有製程通用；差別在「重點證據」與「容易被客戶挑出來的地方」。

### 機械加工

- 追溯單位：機台 + 夾具 + 刀具批號 + 材料爐號；刀具磨耗與換刀點會造成尺寸週期性漂移，SPC 取樣要涵蓋換刀前後
- Control Plan 的尺寸以**關鍵特性（KC）**為主，量測頻率常綁刀具壽命或每 N 件首末件檢
- 多工位 / 多主軸 / 多夾具要各自出 Dimensional Results 與能力研究
- 材質證明（mill cert）、表面粗糙度、形位公差用 CMM + 量具；MSA 要涵蓋 CMM 與手工量具
- 開發件轉量產時 Cpk 常因樣本不足難達標（CNC profile 的 `開發工廠-vs-量產` 有更多說明）

### 射出

- **多穴模每穴都要**出 Dimensional Results 與初期研究；穴號要標記在件上以利追溯
- 製程參數視窗（溫度、壓力、保壓、冷卻時間、模溫）納入 Control Plan 並留紀錄；變更參數視同製程變更
- 材料：樹脂 lot、乾燥條件、回收料（regrind）比例須經客戶核准；材料申報（如 IMDS）依客戶要求
- 模具變更、維修、換模、閒置後再量產通常觸發 PPAP 重提
- 收縮 / 翹曲隨時間穩定，量測前的靜置條件（時間、溫濕度）要明訂（需依材料與客戶驗證）；外觀件另有色板 / 紋面的 AAR

### 壓鑄

- 內部缺陷（氣孔、縮孔）以 X-ray / 洩漏測試 / 剖面檢驗驗證，抽樣或全檢頻率與接受準則依客戶規格（如 VDG P201 類規範，採用哪一版需驗證）
- 製程參數（金屬溫度、模溫、慢/快速射出曲線、真空、增壓）是 PFMEA 與 Control Plan 的核心，須即時監控與留紀錄
- 材料：合金成分（光譜分析）與爐批追溯；機械性質試片依客戶規定
- 多穴 / 模具各穴出尺寸結果；後加工（機械加工）如屬供應商責任，PPAP 範圍要涵蓋鑄造 + 加工兩段
- 模具壽命與熱疲勞導致尺寸/外觀漂移，須有模具保養與壽命追蹤

### 鈑金沖壓

- 重點在模具與材料：板/捲料批號、板厚、機械性質、回彈與成形極限；模具磨耗造成毛邊、尺寸趨勢，須有模具保養週期
- 級進模 / 多工位模具要確認各工位狀態；Dimensional Results 要涵蓋模具各工位或各模次樣本
- **檢具（Checking Aids，第 16 項）**常是重點：3D 曲面件多靠檢具 + CMM，檢具需有驗證與校驗紀錄
- 毛邊方向 / 高度、拉傷、橘皮等外觀缺陷在 AAR 或 Control Plan 明訂；漏沖孔等以防錯（poka-yoke）處理
- 焊接 / 組合件另需熔接強度等性能試驗（依客戶規格）

### 電子組裝

- PPAP 要素多「轉譯」使用：Design Records = Gerber / BOM / 組裝圖；材料 = 零件核准清單（AVL）與替代料客戶核准；零件級可靠度驗證（如 AEC-Q 系列）通常由零件供應商負責，依客戶要求（需驗證）
- 製程管制點：錫膏印刷（SPI）、貼片、回焊溫度曲線、AOI / ICT / FCT；Control Plan 與 PFMEA 圍繞這些站別
- MSA 對象是**測試設備**（ICT / FCT / AOI）而非量具；初期研究常針對測試量測值或製程參數而非尺寸
- 追溯：PCB 序號 / 批號 ↔ 零件 lot ↔ 製程站別資料；MSL 濕敏元件管控、ESD、無鉛 / RoHS 符合性
- 軟體 / 韌體版本與變更管制納入 PPAP 範圍；外觀與工藝接受標準（如 IPC-A-610 Class 2/3）依客戶指定

## 常見誤解

- ❌「拿到 IATF 證就無敵」→ 客戶仍會做製程稽核（VDA 6.3 / 客戶自己的稽核）
- ❌「PPAP 給一次就好」→ 任何變更（圖紙、機台/模具、材料、次供應商、地點）都要依手冊與 CSR 重提
- ❌「Level 3 就是把 18 項全部送出」→ 18 項證據都要備齊，但哪些**提交**、哪些**保存備查**依等級與手冊規定
- ❌「Cpk 高就 OK」→ 還要看製程是否穩定（管制圖）、量測系統是否有效（MSA）、取樣是否涵蓋所有穴位 / 工位 / 班別
- ❌「Cpk ≥ 1.67 是 IATF 或 ISO 9001 的規定」→ 那是 PPAP 初期研究的通用判讀或客戶 CSR，不是 ISO 9001 要求
- ❌「FAI 做過就等於 PPAP」→ FAI / Dimensional Results 只是 18 項要素之一
