# GD&T 幾何尺寸與公差速查

> 此文件用 **ASME Y14.5-2018** 的符號規範（美規）。
> ISO 1101（歐規）符號大致相同但細節有差異 — 看到歐洲客戶圖紙時請對照 ISO 標準確認。

## 為什麼 agent 要懂 GD&T

CAD 圖紙上的「⊕」「⏥」「⌖」「⌭」等符號不是裝飾 — 是工程師告訴你「這個尺寸允許怎麼變動」的精確語言。

- 不懂 GD&T 看圖紙 → 報錯價（公差緊 vs 鬆價差 5-30%）
- 不懂 GD&T 做檢驗 → 量錯方法、誤判 OK/NG
- 不懂 GD&T 寫 SOP → 操作員不知道怎麼夾、怎麼量

## 14 個 GD&T 符號（按類別分）

### 形狀公差（Form — 不需基準）

| 符號 | 名稱         | 中文   | 控制什麼            |
| ---- | ------------ | ------ | ------------------- |
| ⏤    | Straightness | 真直度 | 一條線的直          |
| ⏥    | Flatness     | 真平度 | 一個面的平          |
| ○    | Circularity  | 真圓度 | 圓周斷面的圓        |
| ⌭    | Cylindricity | 圓柱度 | 整個圓柱面的圓 + 直 |

### 輪廓公差（Profile — 可帶基準）

| 符號 | 名稱                 | 中文     | 控制什麼     |
| ---- | -------------------- | -------- | ------------ |
| ⌒    | Profile of a line    | 線輪廓度 | 一條曲線形狀 |
| ⌓    | Profile of a surface | 面輪廓度 | 一個曲面形狀 |

### 方向公差（Orientation — 需基準）

| 符號 | 名稱             | 中文   | 控制什麼          |
| ---- | ---------------- | ------ | ----------------- |
| ∠    | Angularity       | 傾斜度 | 與基準成特定角度  |
| ⊥    | Perpendicularity | 垂直度 | 與基準垂直（90°） |
| ∥    | Parallelism      | 平行度 | 與基準平行        |

### 位置公差（Location — 需基準）

| 符號 | 名稱          | 中文                      | 控制什麼                      |
| ---- | ------------- | ------------------------- | ----------------------------- |
| ⌖    | Position      | 位置度                    | feature 中心相對基準的位置    |
| ◎    | Concentricity | 同心度（少用，2018 移除） | 兩個同軸 feature 的中心軸對齊 |
| ⌯    | Symmetry      | 對稱度（少用，2018 移除） | feature 對基準面對稱          |

> ASME Y14.5-2018 已移除 Concentricity 和 Symmetry — 改用 Position with MMC/LMC 表達。看到舊圖還用要會。

### 跳動公差（Runout — 需基準軸）

| 符號 | 名稱            | 中文   | 控制什麼                      |
| ---- | --------------- | ------ | ----------------------------- |
| ↗    | Circular runout | 圓跳動 | 旋轉時某斷面的偏擺            |
| ⌰    | Total runout    | 全跳動 | 旋轉時整個面的偏擺（圓 + 直） |

## Feature Control Frame 解讀

GD&T 標註寫成「特徵控制框（feature control frame）」：

```
┌─────┬──────┬─────┬─────┬─────┐
│  ⌖  │ ⌀0.05│  Ⓜ  │  A  │ B M │
└─────┴──────┴─────┴─────┴─────┘
   ①    ②     ③     ④    ⑤
```

| 欄位 | 內容                                   |
| ---- | -------------------------------------- |
| ①    | 幾何特徵符號（這裡是 Position）        |
| ②    | 公差值（直徑 0.05 — 一個圓柱形容差區） |
| ③    | 材料條件修飾符（Ⓜ MMC 最大材料條件）  |
| ④    | 主基準（A）                            |
| ⑤    | 次基準（B），帶 MMC 修飾               |

---

## 三大材料條件修飾符

| 符號 | 名稱                             | 意思                                                            |
| ---- | -------------------------------- | --------------------------------------------------------------- |
| Ⓜ   | MMC — Maximum Material Condition | 軸取最大、孔取最小（材料最多時的尺寸） — 公差可隨「離 MMC」放大 |
| Ⓛ    | LMC — Least Material Condition   | 軸取最小、孔取最大（材料最少時的尺寸）                          |
| Ⓡ    | RFS — Regardless of Feature Size | 不管實際尺寸，公差固定（預設 if no symbol）                     |

### Bonus tolerance（紅利公差）

```
原圖：⌀10.00 +0.10/-0.00，Position ⌀0.05 Ⓜ
若實際做出來是 ⌀10.05（離 MMC 已用 0.05）
→ Bonus tolerance = 0.05
→ 實際 Position 容差 = 0.05 + 0.05 = ⌀0.10
```

→ MMC 標註讓量產容易（量到較大孔徑時，位置可以更歪，仍合格）。

## 基準（Datum）系統 — 3-2-1 原則

CNC fixture 設計與檢驗都基於這個：

```
主基準 A → 限制 3 個自由度（一個面，3 點接觸）
次基準 B → 限制 2 個自由度（一個面，2 點接觸）
末基準 C → 限制 1 個自由度（一個面/邊，1 點接觸）
總共限制 6 個自由度（3 平移 + 3 旋轉）
```

→ feature control frame 第 4-5 欄的基準順序（A → B → C）就是這個 stacking。
→ 基準順序錯了，量出來的位置會差。

## 常見誤解

- ❌ **「公差越緊越好」** → 緊公差貴 5-30%，多數 feature 不需要。設計時應該標明 **「為什麼這裡要緊」**。
- ❌ **`Position ⌀0.1` 是邊長 0.1 的方框** → **錯**，是直徑 0.1 的圓形容差區（圓柱形容差，較合直觀）。
- ❌ **Concentricity 跟 Position 一樣** → Concentricity 量中心軸，幾乎只能用昂貴量具量；Position 量 feature 中心，便宜很多。Y14.5-2018 已棄 Concentricity。
- ❌ **看到 ⊥ 就是 90°** → ⊥ 是「相對基準的垂直度公差」，公差值決定能歪多少。沒寫公差就不是 GD&T 標註。
- ❌ **基準 A、B、C 順序可以互換** → 順序決定量測流程，**不能換**。

## 對 agent 的影響

- **`quote-specialist`**：看到緊公差（IT5 / IT6 / Position 0.02 以下）→ 加 5-15% 報價（要量具校驗 + 加嚴 IPQC）
- **`cnc-programmer`**：看到 GD&T → 重新檢視夾治具設計，確認**基準順序與夾持方向一致**
- **`fixture-designer`**：fixture 接觸面要對應主/次/末基準，否則量到的不是設計者要的
- **`quality-inspector`**：要會用 CMM 軟體輸入 feature control frame，依基準順序量
