# OEE 設備總效率（Overall Equipment Effectiveness）

衡量設備真實生產效率的世界共通指標。

---

## 公式

```
OEE = 可用率 × 性能率 × 良率
    = Availability × Performance × Quality
```

| 因子       | 公式                                   | 失分原因                   |
| ---------- | -------------------------------------- | -------------------------- |
| **可用率** | (運轉時間 - 計畫外停機) / 計畫運轉時間 | 故障、缺料、缺人、換型過長 |
| **性能率** | 實際產出 / (理論節拍 × 運轉時間)       | 速度慢、小停機、空轉       |
| **良率**   | 良品數 / 總產出數                      | 不良品、重工、報廢         |

---

## 世界級水準

| OEE    | 評價                  |
| ------ | --------------------- |
| ≥ 85%  | 世界級（World class） |
| 60~85% | 業界平均              |
| 40~60% | 多數工廠真實水準      |
| < 40%  | 嚴重浪費              |

> 多數老闆以為自己工廠 OEE 80%+，實測往往是 50% 上下。

---

## 量測方法

每張工單記錄：

```
A. 計畫運轉時間 = 班別工時 - 計畫保養 - 計畫休息
B. 實際運轉時間 = A - 計畫外停機（故障 + 缺料 + 缺人 + 等檢驗）
C. 實際產出 = 完工件數
D. 理論節拍時間 = 每件理論工時
E. 良品數 = C - 不良數

可用率 = B / A
性能率 = (C × D) / B
良率 = E / C
OEE = 三者相乘
```

---

## 對 agent 的影響

- **產能規劃**（`capacity-planning.md`）：用 OEE 折算，不要用名義產能
- **排程**：低 OEE 機台要安排提早保養 / 改善
- **工時估算**：報價時的工時要對得上實際 OEE 下的產出能力

---

## 改善方向（依失分大小）

| 失分集中 | 改善方向                                     |
| -------- | -------------------------------------------- |
| 可用率低 | TPM（全員生產保養）、預防保養、SMED 快速換模 |
| 性能率低 | 重新設定節拍、改善小停機、減少空轉           |
| 良率低   | SPC、首件強化、防呆 (Poka-Yoke)              |

---

## 常見誤解

- ❌「設備跑多久就是可用率」→ 漏掉空轉與小停機
- ❌「良率 99% 就 OK」→ 還要看可用率與性能率
- ❌ 沒記錄停機原因，只記停機時間 → 改善無從下手
