# pre-quote Hook

在 `quote-specialist` 開始算錢之前先擋一關，確認圖紙資料齊全。資料不齊就**強制中止報價，回問**。

---

## 檢查清單

對 input 圖紙與 RFQ：

- [ ] 圖紙檔案能讀（PDF / DWG / STEP / 圖片）
- [ ] 件名 / 件號明確
- [ ] 材料牌號明確（不是「不鏽鋼」這種模糊描述，要 SUS304 / SUS316L 等）
- [ ] 主要尺寸有公差（不是只標稱尺寸）
- [ ] 表面粗糙度標註（Ra 值）
- [ ] 表面處理規範（如有：陽極厚度、電鍍規範、塗裝色號）
- [ ] 熱處理要求（如有：硬度範圍 HRC、HV）
- [ ] 數量
- [ ] 客戶要求交期
- [ ] 付款條件（如已知）

---

## 失敗處理

任一項缺：

```
🛑 報價暫停 — 缺少必要資訊：
- 材料牌號未指定（圖紙僅標「不鏽鋼」）
- φ20 公差未標註
- 表面處理規範缺
- 數量未確認

請業助回客戶 / 工程確認後再啟動報價。
```

不要在資料不全時硬報。

---

## 例外通行

只有在以下情況可繞過（必須記錄理由）：

- 客戶明確要求「給粗估範圍」（標 [ROUGH ESTIMATE] 不當正式報價）
- 內部試算用（不會送出客戶）
