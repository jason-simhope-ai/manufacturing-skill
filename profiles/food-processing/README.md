## What this profile would cover

食品加工製造特有需求：

- **HACCP** 危害分析與關鍵管制點
- **批次追溯** — 從原料 lot → 成品 lot → 客戶
- **過敏原管理** — 共線生產的污染風險
- **保存期限預測**
- **CIP/SIP** 設備清洗驗證

與機械加工根本差異：

- 製程是**化學/生物**反應（不是切削加工）
- **批次**為單位（不是件數）
- **時效性極強**（保存期、冷鏈）
- **法規嚴格**（GMP、HACCP、FDA、Halal、Kosher）
