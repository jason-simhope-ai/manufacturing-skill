# 食品常見危害與 CCP 範例

> ⚠️ **Alpha / 範例 / 需驗證**：下表所有管制界限都是**教科書或公開指引的範例值**，用來幫助 HACCP 小組討論，**不是法規要求、也不是你工廠的界限**。你的界限必須依產品配方、設備、包裝與**確效試驗（validation）**決定，並由 HACCP 小組簽核。

由 **haccp-coordinator** 使用；[`haccp-plan-review`](../skills/haccp-plan-review.md) 做危害分析時對照。

---

## 三類危害速查

| 類別 | 常見例子                                                   | 常見管制方式                         |
| ---- | ---------------------------------------------------------- | ------------------------------------ |
| 生物 | 沙門氏菌、李斯特菌、病原性大腸桿菌、肉毒桿菌、仙人掌桿菌   | 加熱殺菌、冷卻 / 冷藏、pH、水活性    |
| 化學 | **未標示過敏原**、清潔劑殘留、農藥 / 動物用藥殘留、添加物超量 | 供應商管理、清線、配方與標示核對    |
| 物理 | 金屬、玻璃、硬塑膠、石頭、骨頭                             | 金屬檢測 / X 光、篩網、玻璃政策      |

---

## 1. 加熱殺菌 / 烹煮

| 項目         | 範例（需驗證）                                                     |
| ------------ | ------------------------------------------------------------------ |
| 危害         | 病原菌存活                                                         |
| 典型 CCP     | 殺菌槽 / 烤箱 / 蒸煮出口                                           |
| 範例界限     | 乳品 HTST 巴氏殺菌：72°C / 15 秒；熟食中心溫度 ≥ 75°C（或等效時間溫度組合） |
| 低酸性罐頭   | 須由熱製程專業人員確效（F 值），**不可套用範例**                   |
| 監控         | 連續溫度記錄器 + 每批人工核對；中心溫度用校正過的探針               |
| 常見缺失     | 量表面不量中心、探針沒校正、停電 / 降溫時段沒處理                   |

## 2. 冷卻與冷藏 / 冷凍

| 項目     | 範例（需驗證）                                                     |
| -------- | ------------------------------------------------------------------ |
| 危害     | 加熱後殘存芽孢菌（如產氣莢膜梭菌）在冷卻過慢時增殖                  |
| 範例界限 | 冷卻：2 小時內由 57°C 降到 21°C、再 4 小時內降到 5°C 以下（美系指引範例） |
| 儲存     | 冷藏常見 ≤ 7°C、冷凍常見 ≤ -18°C（台灣法規數值需驗證）              |
| 監控     | 冷藏庫溫度連續記錄 + 異常警報；出貨車溫度紀錄                       |
| 常見缺失 | 只記早上一次溫度、警報沒人接、除霜時段溫度未說明                    |

## 3. 金屬檢測 / X 光

| 項目     | 範例（需驗證）                                                          |
| -------- | ----------------------------------------------------------------------- |
| 危害     | 設備磨耗、篩網破損、刀片碎片                                            |
| 範例界限 | 測試片：鐵 Ø1.5 mm、非鐵 Ø2.0 mm、不鏽鋼 Ø2.5 mm（依產品與開口尺寸差異大） |
| 監控     | 開線、每 N 小時、換品項、收線時用測試片測試；剔除裝置功能確認           |
| 偏差處理 | 測試失敗 → 上一次合格測試之後的產品全部隔離重檢                         |
| 常見缺失 | 測試片放在包裝最好測的位置、剔除箱沒上鎖、剔除品沒調查                  |

## 4. 過敏原

| 項目     | 範例（需驗證）                                                       |
| -------- | -------------------------------------------------------------------- |
| 危害     | 共線生產交叉接觸、**標示與配方不符**（最常見的回收原因之一）          |
| 台灣標示 | 衛福部公告應標示的過敏原品項（甲殼類、芒果、花生、牛奶羊奶、蛋、堅果、芝麻、含麩質穀物、大豆、魚類、亞硫酸鹽等，**品項與門檻需驗證**） |
| 管制方式 | 生產排序（無過敏原先做）、清線 + 目視 / 快篩確認、包材與配方核對        |
| 分類     | 清線多為 OPRP；**包裝線標示核對**有些工廠列為 CCP — 由小組決定       |
| 常見缺失 | 換配方沒換包材、舊包材混用、代工原料過敏原資訊沒更新                  |

## 5. 其他異物（玻璃、硬塑膠、石頭）

| 項目     | 範例                                                       |
| -------- | ---------------------------------------------------------- |
| 管制方式 | 玻璃與硬塑膠清冊 + 定期巡檢、篩網完整性檢查、原料除石       |
| 分類     | 多為 PRP / OPRP；若無後續步驟可去除且風險高，才考慮列 CCP |
| 常見缺失 | 篩網破了不知道何時破的 → 無法界定影響批次                  |

## 用 pH / 水活性降低風險（範例）

| 條件                 | 範例意義（需驗證）                     |
| -------------------- | -------------------------------------- |
| pH ≤ 4.6             | 一般認為可抑制肉毒桿菌生長（酸性 / 酸化食品） |
| 水活性 aw ≤ 0.85     | 多數病原菌難以生長                     |

兩者都要**實測並記錄**，配方改變就要重測。

---

## 給 agent 的使用規則

1. 引用本文數值時**一律附「範例，需依確效結果設定」**
2. 使用者的界限與範例不同 ≠ 錯誤；只問「依據是什麼」
3. 發現實測值超出使用者自己的界限 → 標為偏差，交 HACCP 小組判定
4. 永遠不說「這個溫度夠安全」— 安全與否由確效資料與小組判斷
