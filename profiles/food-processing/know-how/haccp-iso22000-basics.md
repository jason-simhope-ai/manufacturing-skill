# HACCP 與 ISO 22000 基礎

> ⚠️ **Alpha**：本文是 agent 操作參考用的精華版，**不取代官方標準與法規原文**，也不取代 HACCP 管制小組、食品技師或法規顧問。標「需驗證」處請以衛福部食藥署與驗證機構現行版本為準。

由 **haccp-coordinator** 與 **traceability-officer** 使用。

## 三層關係：GHP → HACCP → ISO 22000 / FSSC 22000

| 層級            | 是什麼                                                 | 台灣情境                                                        |
| --------------- | ------------------------------------------------------ | --------------------------------------------------------------- |
| GHP / PRP       | 基本衛生：廠房、清潔、病媒、人員衛生、供水、溫控       | 「食品良好衛生規範準則」— 食品業者普遍適用（範圍需驗證）        |
| HACCP           | 針對產品與製程的危害分析 + 關鍵管制點                  | 「食品安全管制系統準則」— 公告業別強制（業別清單需驗證）        |
| ISO 22000       | 管理系統（PDCA）+ HACCP + PRP + OPRP，可第三方驗證     | 自願性；外銷或大型通路客戶常要求                                |
| FSSC 22000      | ISO 22000 + ISO/TS 22002-x（PRP）+ 額外要求，GFSI 承認 | 自願性；國際品牌客戶常要求（現行版本需驗證）                    |
| TQF             | 台灣優良食品驗證                                       | 自願性；國內通路認知度高                                        |

**順序很重要**：GHP 沒做好就上 HACCP，等於在沙地上蓋房子。

## HACCP 7 大原則

| #   | 原則           | 一句話                                         |
| --- | -------------- | ---------------------------------------------- |
| 1   | 危害分析       | 每個步驟可能出現哪些生物、化學、物理危害？     |
| 2   | 決定 CCP       | 哪些步驟必須管住，否則危害會留到消費者手上？   |
| 3   | 建立管制界限   | 每個 CCP 合格與不合格的分界數值                |
| 4   | 監控           | 誰、用什麼、多久量一次、記在哪                 |
| 5   | 矯正措施       | 超出界限時怎麼恢復管制、受影響產品怎麼處置     |
| 6   | 確認（驗證）   | 怎麼證明整套系統真的有效                       |
| 7   | 文件與紀錄     | 全部寫下來，並保存到規定期限                   |

前置 5 步（組小組、產品描述、預定用途、流程圖、現場確認）+ 7 原則 = **12 步驟**，檢查清單見 [`haccp-plan-review`](../skills/haccp-plan-review.md)。

## 前提方案（PRP）常見項目

依 ISO/TS 22002-1 架構（食品製造業）：

- 廠房與周邊、動線（生熟區分、人流物流）
- 公用設施：水、空氣、蒸汽、壓縮空氣（接觸食品者）
- 廢棄物處理、病媒防治
- 設備適用性、清潔消毒（含 CIP）、預防保養
- 採購與供應商管理（原料規格、CoA、供應商評核）
- 交叉污染預防：**過敏原管理**、異物管理（玻璃、硬塑膠、木材政策）
- 人員衛生、健康檢查、教育訓練
- 重工管理、產品回收程序、倉儲、標示

## CCP vs OPRP vs PRP（ISO 22000:2018）

| 項目           | PRP                | OPRP                                       | CCP                                           |
| -------------- | ------------------ | ------------------------------------------ | --------------------------------------------- |
| 來源           | 基本衛生條件       | 危害分析結果                               | 危害分析結果                                  |
| 針對           | 整體環境           | 特定顯著危害                               | 特定顯著危害                                  |
| 判斷標準       | 程序是否執行       | **行動準則**（可量測或可觀察）             | **管制界限**（必須可量測）                    |
| 失效時         | 矯正               | 評估產品是否受影響                         | 產品視為**潛在不安全**，依程序處置            |
| 例子           | 每日清潔、病媒防治 | 過敏原清線目視檢查、篩網完整性檢查         | 殺菌溫度 / 時間、金屬檢測                     |

> 同一個管制措施在不同工廠可能被分成 OPRP 或 CCP，取決於危害分析。**分類由 HACCP 小組決定並寫明理由。**

## 紀錄管理

- **監控紀錄**：當下填寫、不得預填；用原子筆；更正用單線劃掉 + 簽名日期，不可塗改液
- **覆核**：監控者以外的人覆核（建議當日或次一工作日內 — 範例）
- **偏差紀錄**：事實、受影響批次、處置、根因、簽核人
- **保存期限**：常見要求為至少保存到產品有效日期後一段期間（**具體年限依法規與客戶要求，需驗證**）
- **電子紀錄**：權限控管、修改留痕跡；Excel 共用檔不等於可信紀錄

## 稽核常見缺失（自我檢查用）

1. 流程圖與現場不符（新設備、新動線沒更新）
2. 危害分析沒有寫「為什麼不是 CCP」的理由
3. 管制界限沒有確效依據，或與作業指導書數字不一致
4. 監控紀錄數值長期一模一樣、或明顯事後補填
5. 偏差有紀錄但沒有產品處置與簽核
6. 溫度計 / 金屬檢測機校正或測試紀錄過期
7. 過敏原：配方變更後標示沒同步更新
8. 回收演練沒做、或做了沒有改善事項追蹤
9. HACCP 小組成員異動，訓練紀錄沒補
10. 年度再確認（reverification）沒做或只有一句「無變更」

## AI 在這裡的界線

- ✅ 整理文件、檢查紀錄完整性、起草偏差報告與訓練題目
- ✅ 用白話解釋條文概念、提醒可能漏掉的危害
- ❌ 判定 CCP 偏差可否放行、決定回收、簽核任何紀錄
- ❌ 當作法規最終解釋 — 疑義請洽主管機關或法規顧問
