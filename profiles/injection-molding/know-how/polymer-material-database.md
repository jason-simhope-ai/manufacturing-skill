# 常用塑料加工特性快查

> ⚠️ **Alpha 警告**：表格內值為**業界泛用範圍**。
> **量產時務必依你採購的特定材料 grade 的 supplier datasheet 為準** — 同名料（例如「PP」）不同 grade 的 MFI、收縮率、UV 穩定性差異很大。
> 此文件僅供：報價快速估算、agent prompt 參考、新人訓練。**不可作為工藝參數鎖定根據**。

## 通用熱塑性塑料特性表

| 材料            | 中/英文                | 料溫 (°C) | 模溫 (°C) | 收縮率 (%) | 乾燥需求        | 特性                               |
| --------------- | ---------------------- | --------- | --------- | ---------- | --------------- | ---------------------------------- |
| **PP**          | 聚丙烯 / Polypropylene | 200~280   | 30~80     | 1.0~2.5    | 一般不需        | 便宜、流動性好、耐化學、不耐 UV    |
| **PE-HD**       | 高密度聚乙烯           | 180~260   | 20~60     | 1.5~4.0    | 不需            | 韌、耐衝、低剛性、不耐高溫         |
| **PS**          | 聚苯乙烯 / Polystyrene | 180~260   | 20~60     | 0.4~0.7    | 80°C × 1~2h     | 透明、脆、便宜、易加工             |
| **HIPS**        | 高衝聚苯乙烯           | 180~260   | 20~60     | 0.4~0.8    | 80°C × 1~2h     | PS 加耐衝、不透明                  |
| **ABS**         | ABS                    | 200~270   | 40~80     | 0.4~0.8    | **80°C × 2~4h** | 通用工程塑、外觀好、易電鍍         |
| **PMMA**        | 壓克力 / Acrylic       | 220~260   | 60~90     | 0.2~0.8    | **80°C × 4h**   | 透明度最高、易刮、UV 穩定          |
| **PC**          | 聚碳酸酯               | 280~320   | 80~120    | 0.5~0.7    | **120°C × 4h**  | 高耐衝、透明、耐熱、貴             |
| **PA6**         | 尼龍 6                 | 230~280   | 40~80     | 0.5~1.5    | **80°C × 4h**   | 強度好、耐磨、吸濕嚴重             |
| **PA66**        | 尼龍 66                | 270~310   | 60~90     | 0.8~1.5    | **80°C × 4h**   | PA6 升級版、耐溫更高               |
| **PA66 + GF30** | 30% 玻纖補強           | 280~320   | 80~110    | 0.3~0.8    | **80°C × 4h**   | 結構件、耐熱、收縮小、纖維取向問題 |
| **POM**         | 聚甲醛 / Acetal        | 180~220   | 60~110    | 1.8~2.5    | 不需（短時 OK） | 自潤、耐磨、酸敏感、極窄加工窗口   |
| **PBT**         | 聚對苯二甲酸丁二酯     | 240~270   | 60~90     | 1.0~2.0    | **120°C × 4h**  | 電氣件、耐溫、易吸濕               |
| **PET**         | 聚對苯二甲酸乙二酯     | 270~290   | 100~140   | 1.5~2.5    | **150°C × 4h**  | 飲料瓶（射出較少，多用吹塑）       |
| **TPU**         | 熱塑性聚胺酯           | 180~220   | 20~50     | 0.6~1.2    | **80°C × 2~3h** | 軟、耐磨、耐油                     |
| **PEEK**        | 聚醚醚酮               | 360~400   | 150~200   | 1.0~1.5    | **150°C × 3h**  | 耐溫 250°C、貴、半導體/醫療件      |

## 加工窗口（process window）寬窄

| 寬窗口（容易調）              | 中等                     | 窄窗口（細心控）                      |
| ----------------------------- | ------------------------ | ------------------------------------- |
| PP, PE-HD, PS, HIPS, ABS, TPU | PMMA, PC, PA6, PA66, PBT | POM, PEEK, PA66 + GF30, 高 MFI 結晶料 |

→ 窄窗口料報價時應加 5~10% 製程風險加成。

## 乾燥不足的後果（為什麼乾燥很重要）

| 材料 | 不乾燥後果                             |
| ---- | -------------------------------------- |
| ABS  | 表面銀紋 (silver streak)               |
| PC   | 分子量降低 → 強度損失 30%+，肉眼看不出 |
| PA   | 表面銀紋 + 分子鏈水解 → 韌性損失       |
| PBT  | 嚴重水解 → 強度大幅降低                |
| PMMA | 銀紋 + 透明度下降                      |

→ **PC、PA、PBT 不乾燥就射出 = 燒錢做廢品**。

## 環境法規對照（簡表）

| 法規 / 認證  | 影響                                                  |
| ------------ | ----------------------------------------------------- |
| RoHS         | 禁鉛 / 鎘 / 汞 / 六價鉻 / PBB / PBDE — 所有 EU 銷售件 |
| REACH        | 化學物質登記 — 嚴格、定期更新 SVHC 清單               |
| UL 94        | 阻燃等級（V-0 / V-1 / V-2 / HB）                      |
| FDA 21 CFR   | 食品接觸材料認證 — 食品包裝必備                       |
| USP Class VI | 醫療器材生物相容性                                    |
| Halogen-free | 無鹵阻燃 — 電子業常見要求                             |

→ 客戶要 spec 中標明上述任一，材料採購要附對應 supplier 證明（COA、Compliance Statement）。

## 用此表的方式

1. **報價時**：查料溫 / 模溫 / 收縮率 → 估 cycle time + 容差預留
2. **mold-designer 設計時**：看收縮率 → 模具尺寸補償；看乾燥需求 → 跟客戶確認設備
3. **不良處理時**：對照 [`common-defects`](common-defects.md) — 通常材料是第二輪檢查項
