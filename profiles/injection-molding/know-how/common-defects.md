# 射出成型常見不良對策樹

> ⚠️ **Alpha**：對策表為業界共通通識，**特定材料 / 特定機台** 的細節須以該材料 datasheet 與機台 manual 為準。

由 **mold-designer** 與 **molding-process-engineer**（v0.2 預計新增）使用。

---

## 通用順序：先設計、再製程、最後材料

碰到不良不要先動製程參數。順序：

1. **設計問題嗎**？(肉厚 / 脫模角 / 澆口位置 / 冷卻佈置) → 改設計成本最低長期最划算
2. **模具問題嗎**？(磨耗 / 排氣 / 表面拋光 / 對位) → 修模
3. **製程問題嗎**？(料溫 / 模溫 / 射壓 / 保壓 / 速度) → 調參數，最快但治標
4. **材料問題嗎**？(乾燥度 / 批號 / 添加劑) → 換批 / 調乾燥

## 1. Short shot 短射

**症狀**：成品某個區域沒填滿，缺料。

| 可能根因                      | 對策                             |
| ----------------------------- | -------------------------------- |
| 設計：肉壁太薄                | 增厚至材料下限以上               |
| 設計：流長比 (L/T ratio) 過大 | 改澆口位置縮短流長               |
| 設計：澆口在最薄處            | 改澆口至最厚處                   |
| 模具：排氣不足                | 增排氣槽（一般 0.02~0.05 mm 深） |
| 製程：射壓不足                | 提高射壓                         |
| 製程：射速太慢                | 提高射速（特別是壁薄件）         |
| 製程：料溫過低                | 提高料溫 10~20°C                 |
| 製程：模溫過低                | 提高模溫                         |
| 材料：MFI 太低（流動性差）    | 換高流動級材料                   |
| 材料：含水率高                | 確認乾燥條件                     |

---

## 2. Sink mark 縮水痕

**症狀**：表面（通常厚壁、boss、rib 後面）凹陷。

| 可能根因                              | 對策                        |
| ------------------------------------- | --------------------------- |
| 設計：rib / boss 太厚（> 0.6 × 母肉） | 減厚或加 cored-out 結構     |
| 設計：肉壁太厚                        | 整體減厚或加加強筋          |
| 製程：保壓不足或時間不夠              | 提高保壓壓力 / 延長保壓時間 |
| 製程：澆口冷凍時間早於保壓結束        | 加大澆口直徑                |
| 製程：模溫過高                        | 降模溫（讓表面提早凝固）    |
| 材料：結晶塑料縮率高                  | 切到非結晶料或加 GF 補強    |

---

## 3. Warpage 翹曲

**症狀**：件出模後變形（彎曲、扭曲、平面度差）。

| 可能根因                         | 對策                        |
| -------------------------------- | --------------------------- |
| 設計：肉厚不均                   | 重新平衡肉厚                |
| 設計：玻纖補強料的纖維方向       | 改澆口位置使纖維對稱        |
| 模具：兩半模冷卻不平衡           | 重新設計冷卻水路            |
| 製程：保壓不足                   | 提高保壓                    |
| 製程：頂出太早                   | 延長冷卻時間                |
| 製程：模溫不平衡（一邊高一邊低） | 校正水路 / 模溫機           |
| 材料：結晶料 + 厚薄不均          | 換非結晶料（PP→ABS）或加 GF |

> 玻纖補強料的翹曲問題 90% 來自纖維取向。模流分析 (Moldflow) 對此特別重要。

---

## 4. Flash 毛邊

**症狀**：分模面 / 滑塊 / 頂針處有溢料。

| 可能根因                           | 對策            |
| ---------------------------------- | --------------- |
| 模具：分模面磨耗                   | 修模 / 重新合模 |
| 模具：對位不良                     | 檢查導柱        |
| 製程：鎖模力不足                   | 換更大噸位機台  |
| 製程：射壓 / 保壓過高              | 降壓            |
| 製程：料溫過高 → 黏度低 → 流入縫隙 | 降料溫          |
| 製程：射出量過剩                   | 校 shot weight  |

---

## 5. Silver streak / splay 銀紋

**症狀**：表面有銀色閃光紋路（看起來像水痕）。

| 可能根因                   | 對策                                                     |
| -------------------------- | -------------------------------------------------------- |
| 材料：含水率過高           | 嚴格乾燥（PA66 80°C × 4h、PC 120°C × 4h、ABS 80°C × 2h） |
| 材料：含揮發份             | 換批 / 通知供應商                                        |
| 製程：料溫過高致裂解       | 降料溫                                                   |
| 製程：射速過快剪切過熱     | 降射速或設多段射速                                       |
| 模具：排氣不足致燒焦氣帶銀 | 增排氣                                                   |

> 出現銀紋第一個檢查永遠是**乾燥**。乾燥沒解決，調製程是浪費時間。

---

## 6. Weld line 結合線

**症狀**：兩道料流匯合處有可見線、外觀差、強度低。

| 可能根因                                 | 對策                            |
| ---------------------------------------- | ------------------------------- |
| 設計：多澆口必有 weld line               | 改單澆口（如 part size 允許）   |
| 設計：流向繞過孔 / 凸出物                | 重新設計避免分流                |
| 設計：weld line 落在外觀面               | 改澆口位置移到非外觀面          |
| 製程：料溫低致融合不良                   | 提高料溫                        |
| 製程：模溫低                             | 提高模溫                        |
| 製程：射速慢致前緣冷卻                   | 提高射速                        |
| 模具：weld line 處排氣不足               | 增排氣                          |
| 材料：玻纖補強料 weld line 強度損失 50%+ | 結構件須避免 weld line 在受力處 |

## 不良處理流程（給 quality-inspector + production-planner）

```
發現不良
  ↓
[1] 隔離本批不良品
  ↓
[2] 抽更大樣本確認比例
  ↓
[3] 不良比例 > AQL → 整批複檢；< AQL → 接受單件處置
  ↓
[4] 對照本表找根因 → 啟動 8D
  ↓
[5] 暫時對策（D3）：可能調製程 / 換批料
  ↓
[6] 永久對策（D5）：通常改設計或改模具
  ↓
[7] 監控（D6 / D7）後續同件不良率回到 baseline
```

---

## Anti-patterns

- ❌ 不良一發生就先動製程 — 通常治標不治本
- ❌ 改製程不記錄 — 下批重複出問題沒人記得當時怎麼改
- ❌ 不良品 rework 後混進良品堆 — IATF 客戶會抓出來
- ❌ 廠商換批不通知品管做 IQC 加嚴 — 多種不良從這裡來
