# IPC-A-610 電子組裝可接受性 — 導讀

> ⚠️ **Alpha / 需驗證**：IPC-A-610 是 IPC 的付費標準，本文**只做導讀與分類**，不重製條文、圖片或允收數字。標「需驗證」的內容請對照你們購買、客戶指定的**版本原文**。各版本（例如 H 版、J 版）之間條款與數字有調整，版本以 IPC 官方最新公告為準（需驗證）。

由 **ems-quality-analyst** 與 **smt-process-engineer** 使用。

---

## 它是什麼、不是什麼

| 標準                 | 回答的問題                         | 誰在用                 |
| -------------------- | ---------------------------------- | ---------------------- |
| **IPC-A-610**        | 組裝好的板子**看起來**可不可以收   | 檢驗員、品質、客戶     |
| **IPC J-STD-001**    | 焊接**製程與材料**要怎麼做才合格   | 製程、生產             |
| **IPC-7711/7721**    | 返修、修改、修補要怎麼做           | 返修站、品質           |
| **IPC-A-600**        | 裸板（PCB 本身）可不可以收         | IQC、PCB 供應商        |
| **J-STD-020 / 033**  | 濕敏元件分級與處理                 | 倉庫、製程、品質       |

常見誤解：「我們有 IPC-A-610，所以製程沒問題」— 610 是**驗收**標準；製程要求在 J-STD-001。客戶合約常兩者同時指定。

## 三個產品等級（Class）

| Class | 名稱（意譯）             | 典型產品（範例）                       | 概念                         |
| ----- | ------------------------ | -------------------------------------- | ---------------------------- |
| 1     | 一般電子產品             | 消費性、功能為主的產品                 | 能用就好，外觀要求最低       |
| 2     | 專用服務電子產品         | 工業設備、通訊、多數商用產品           | 要求可靠、長壽命，允許少量外觀瑕疵 |
| 3     | 高性能 / 嚴苛環境電子產品 | 醫療維生、航太、部分汽車安全相關       | 不允許停機，要求最嚴         |

- **Class 由客戶決定**，寫在圖面、合約或採購單上。沒寫時不要自己假設 — 列入「需客戶確認」
- 同一片板子可能有局部要求更嚴的區域（依客戶圖面）
- 汽車電子另有 IPC 的汽車附錄或客戶特定要求（CSR），需驗證適用文件

## 四種判定狀態

| 狀態                          | 意思                                       | 你該做什麼                         |
| ----------------------------- | ------------------------------------------ | ---------------------------------- |
| **Target（目標）**            | 接近理想，但不是必須                       | 無                                 |
| **Acceptable（允收）**        | 不理想但不影響形狀、配合、功能與可靠度     | 放行                               |
| **Process Indicator（製程警示）** | 不影響功能，但代表製程偏離，**不是不良**   | 記錄、追趨勢、交給製程改善         |
| **Defect（不良）**            | 依該 Class 不允收                          | 依程序處置（重工/返修/報廢/特採）  |

注意：**Process Indicator 不能當不良退貨，也不能忽視**。它是 SPC 的訊號，交給 [`smt-process-engineer`](../agents/smt-process-engineer.md)。

處置（disposition）— 重工、返修、特採 — 是品質與客戶的決定，不是檢驗員或 AI 的決定。

## 常見允收條款家族（導讀用）

以下是 IPC-A-610 內容的大分類，方便把現場爭議歸到正確章節去查原文。**具體允收數字請查原文**，下面只列「要查什麼」：

| 家族                       | 現場常見爭議                                      | 查原文時注意                                                   |
| -------------------------- | ------------------------------------------------- | -------------------------------------------------------------- |
| 焊點通則                   | 潤濕角、冷焊外觀、焊料過多/過少                   | 無鉛焊點外觀與有鉛不同（較暗、較粗糙），不要用有鉛標準判       |
| SMT 片式元件（chip）       | 側面偏移、末端偏移、焊點高度、墓碑                | 側面偏移允收比例因 Class 而異（需驗證）；末端偏出通常不允收    |
| SMT 鷗翼腳 / J 腳 IC        | 腳偏移、腳跟填錫、共面性                          | 腳跟（heel）填錫要求依 Class 不同                              |
| 底部端子元件（QFN 等）     | 側面看不到焊點、散熱焊盤空洞                      | 外觀可視條件有限，常需 X-ray；空洞率多由客戶或其他標準另訂     |
| BGA                        | 空洞、橋接、枕頭效應、錫球缺損                    | 610 主要靠 X-ray 判讀；BGA 設計與空洞另見 IPC-7095（需驗證）   |
| 通孔元件（THT）            | 垂直填錫（barrel fill）高度、焊錫面/元件面潤濕    | 填錫百分比依 Class 與是否接大銅面而不同（需驗證）              |
| 元件損傷                   | 陶瓷電容裂、IC 本體缺角、腳彎                     | 裂紋通常一律不允收；缺角依位置與大小                           |
| 板面狀況                   | 白斑（measling）、分層、燒焦、防焊剝落            | 部分屬裸板範圍，與 IPC-A-600 對照                              |
| 清潔度                     | 助焊劑殘留、異物、錫珠                            | 免洗（no-clean）殘留不等於不良；錫珠依大小與是否固定           |
| 標示 / 塗覆 / 線材 / 硬體  | 標籤位置、三防漆覆蓋、線束、螺絲扭力標記          | box build 常落在這幾章                                         |

## 現場使用建議

1. **檢驗員要受訓**：IPC 有認證訓練（CIS / CIT），客戶稽核常問誰有證照（需驗證你們客戶的要求）
2. **建立廠內「照片判例庫」**：同一缺陷的允收/不良照片並列，對照條款編號 — 這是 AI 可以幫忙整理的部分
3. **爭議焊點流程**：照片 + 放大倍率 + 條款編號 + 判定人 + 日期，留紀錄
4. **版本管理**：客戶指定版本不一定是最新版；廠內同時存在多個版本時要能追溯
