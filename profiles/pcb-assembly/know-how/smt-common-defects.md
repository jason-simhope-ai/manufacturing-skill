# SMT 常見焊接不良對策表

> ⚠️ **Alpha**：成因與對策為業界通識。所有數字都是**範例 / 需驗證**，實際值以錫膏 datasheet、元件 datasheet、你們的設備能力與客戶規範為準。不同錫膏化學、不同爐子、不同板厚，最佳值差很多。

由 **smt-process-engineer** 與 **ems-quality-analyst** 使用。

---

## 通用順序：先數據、先上游

碰到不良，**不要先動回焊爐**。順序：

1. **確認是真不良**：AOI 報警先複判；誤判是程式問題，不是製程問題
2. **集中還是分散**？集中在特定位置 → 先懷疑**設計 / 鋼板**；分散在很多位置 → 懷疑**製程 / 材料**
3. **看 SPI**：印刷體積、偏移有沒有異常
4. **看貼片**：偏移、壓力、拋料、元件庫角度
5. **看回焊**：要**實測 profile**，不是看爐子設定值
6. **看材料**：錫膏（回溫、開封時間、批號）、元件可焊性、MSL 超時、PCB 表面處理

每次只改一個變數，改了記錄，驗證後才固化（走 core [`engineering-change-process`](../../../core/skills/engineering-change-process.md)）。

## 1. 墓碑 / 立碑（Tombstoning）

**症狀**：片式元件（0402、0201 等小元件最常見）一端翹起，像墓碑立著。

**機理**：兩端焊錫熔化時間或潤濕力不平衡，一端先熔把元件拉起。

| 可能根因                                   | 對策                                                   |
| ------------------------------------------ | ------------------------------------------------------ |
| 設計：一端焊墊接大銅面（熱容量不對稱）     | 加熱阻隔（thermal relief）、焊墊對稱                   |
| 設計：焊墊過大或間距過大                   | 依 IPC-7351 / datasheet 修正焊墊                       |
| 印刷：兩端錫膏量不均                       | 查 SPI 兩端體積差；清開孔                              |
| 貼片：偏移、一端壓入較深                   | 校正座標與吸嘴高度                                     |
| 回焊：升溫通過熔點太快、板面溫差大         | 延長或調整 soak，降低通過液相線前的溫差（範例方向）    |
| 材料：元件端電極可焊性差                   | 換批驗證、檢查儲存條件                                 |

---

## 2. 短路 / 橋接（Bridging）

**症狀**：相鄰腳或焊墊被焊錫連在一起，細間距 IC、QFN、連接器最常見。

| 可能根因                                   | 對策                                                         |
| ------------------------------------------ | ------------------------------------------------------------ |
| 設計：細間距焊墊間沒有防焊橋               | DFM 回饋；確認 PCB 廠防焊能力                                |
| 鋼板：開孔過大或太厚                       | 開孔內縮（範例約 5~10%，需驗證）、評估鋼板厚度               |
| 印刷：鋼板底部沾錫、密合不良、錫膏塌陷     | 提高擦拭頻率、加板底支撐、檢查錫膏回溫與使用時間             |
| 印刷：偏移                                 | 檢查 MARK 辨識、鋼板張力                                     |
| 貼片：下壓過深把錫膏擠出                   | 調整貼裝高度 / 壓力                                          |
| 回焊：恆溫段太長導致錫膏塌陷（依錫膏）     | 依錫膏 datasheet 調整 soak                                   |

**數據提示**：SPI 體積上限收緊通常比事後 AOI 抓更有效。

---

## 3. 枕頭效應（Head-in-Pillow, HiP）

**症狀**：BGA 錫球與錫膏都熔化了，但沒有融合，像頭靠在枕頭上。**AOI 看不到、ICT/FCT 可能時好時壞**，常在客戶端才發作。

**機理**：回焊時元件或 PCB 翹曲，錫球短暫離開錫膏；錫球表面氧化或助焊劑已耗盡，再接觸時無法融合。

| 可能根因                               | 對策                                                         |
| -------------------------------------- | ------------------------------------------------------------ |
| 元件/PCB 在高溫下翹曲                  | 向元件供應商要高溫翹曲資料；調整 profile 降低板面溫差        |
| 錫球氧化（儲存不當、MSL 超時）         | 檢查儲存與 MSL 紀錄                                          |
| 助焊劑活性不足或在峰值前耗盡           | 評估錫膏化學；縮短過長的 soak（依錫膏建議）                  |
| 錫膏量不足                             | 檢查開孔與 SPI；必要時加大或階梯鋼板                         |
| 氮氣環境（如有）                       | 評估氮氣回焊對潤濕的改善（需驗證成本效益）                   |

**偵測**：X-ray（傾斜角度較有機會看出）、染色拉拔試驗（dye-and-pry，破壞性）、切片。

---

## 4. 空洞（Voids）

**症狀**：X-ray 看到焊點內部氣泡。BGA 錫球、QFN / 功率元件散熱焊盤最常見。

**機理**：助焊劑揮發物或水氣來不及從焊點逃出。

| 可能根因                                 | 對策                                                               |
| ---------------------------------------- | ------------------------------------------------------------------ |
| 散熱焊盤整片開孔                         | 分格開孔（windowpane），覆蓋率範例約 50~70%（需驗證）              |
| via-in-pad 未塞孔                        | 要求塞孔蓋銅                                                       |
| profile：揮發物排出時間不足              | 依錫膏建議調整 soak / TAL                                          |
| 錫膏化學（部分配方空洞較多）             | 做錫膏比較試驗                                                     |
| 元件、PCB 吸濕                           | MSL 管控、PCB 烘烤（依 PCB 廠建議）                                |
| 製程極限                                 | 真空回焊（設備投資，需驗證效益）                                   |

**允收**：空洞率允收值常由客戶規範或專門標準另訂（BGA 參考 IPC-7095、底部端子元件參考 IPC-7093，需驗證）。常見客戶規範範例「單一焊點空洞面積 ≤ 25%」只是**範例**，以客戶要求為準。

---

## 5. 少錫 / 空焊（Insufficient solder / Open）

**症狀**：焊點錫量不足、潤濕不完全或完全沒接上。

| 可能根因                                  | 對策                                                              |
| ----------------------------------------- | ----------------------------------------------------------------- |
| 鋼板：面積比太低，錫膏脫模不良            | 面積比經驗值 ≥ 約 0.66（IPC-7525 指引，需驗證）；加大開孔或減薄鋼板 |
| 印刷：開孔堵塞、錫膏乾掉                  | 擦拭頻率、錫膏在鋼板上的時間、回溫流程                            |
| 設計：via 在焊墊旁吸錫（wicking）         | 防焊覆蓋 via、塞孔                                                |
| 元件：腳共面性差（IC）                    | IQC 抽驗共面性、檢查托盤運輸                                      |
| 回焊：峰值溫度或 TAL 不足（大熱容量元件） | 實測該位置溫度，依錫膏建議調整                                    |
| 材料：PCB 表面處理氧化 / 過期             | 確認 PCB 存放期限與包裝                                           |

## 其他常見不良（簡表）

| 不良                    | 第一個要查的地方                               |
| ----------------------- | ---------------------------------------------- |
| 錫珠（solder balls）    | 錫膏吸濕、印刷偏移、升溫太快                   |
| 元件偏移                | 座標檔角度、貼片精度、焊墊不對稱               |
| 極性錯誤                | 元件庫/座標檔 rotation 定義、首件確認          |
| MLCC 裂                 | 分板應力、吸嘴下壓、靠近 V-cut                 |
| 冷焊 / 潤濕不良         | 實測 profile、錫膏與元件可焊性                 |

## 回焊 profile 範例區間（SAC 系無鉛錫膏）

**範例 / 需驗證** — 只用來判斷「是不是差很遠」，不能當規格：

| 參數                      | 範例                          |
| ------------------------- | ----------------------------- |
| 液相線（SAC305 附近）     | 約 217~220 °C                 |
| 升溫斜率                  | ≤ 約 3 °C/s                   |
| 恆溫（soak）              | 約 150~200 °C、60~120 s       |
| TAL（液相線以上時間）     | 約 45~90 s                    |
| 峰值                      | 約 235~250 °C，且不超過元件耐溫（J-STD-020 分級，依元件 datasheet） |
