# ETO 整機報價拆解 Skill

> ⚠️ **Alpha**：成本結構依接單設計設備廠的一般實務整理。**本文所有數字（工時、費率、比例、天數）都是「範例」**，請換成貴公司的實績資料。產出是工程估算草稿，正式報價由權責主管核准。

由 **eto-quote-engineer** 主導；零件級成本委派 core **quote-specialist**（流程見 core [`01-報價`](../../../core/skills/01-報價.md)）。

---

## 0. 報價類型

| 類型              | 何時用                             | 標示                    | 誤差範圍（範例） |
| ----------------- | ---------------------------------- | ----------------------- | ---------------- |
| 預算報價          | 客戶編預算、規格未凍結             | `[預算報價]`            | ±20–30%          |
| 正式報價          | 規格凍結、選配全部確認             | 正式報價編號            | 依內部規定       |
| 變更追加報價      | 規格凍結後的變更（見重報價觸發）   | 引用原報價編號 + 變更單 | 依內部規定       |

規格未凍結 → 只能出預算報價（[`pre-quote`](../hooks/pre-quote.md) ETO 閘門）。

每一列一個可選項；**狀態欄不能空白**。

| #   | 項目                   | 選項                        | 狀態          | 成本影響（範例） | 備註                       |
| --- | ---------------------- | --------------------------- | ------------- | ---------------- | -------------------------- |
| B0  | 基本機                 | 標準機架、標準工作範圍      | 已確認        | 基準             | 沿用既有設計約 70%（範例） |
| O1  | 上下料方式             | 人工 / 輸送帶 / 機械手臂    | `[需澄清]`    | 0 / +A / +B      | 影響節拍與安全防護         |
| O2  | 控制器品牌             | 我方標準 / 客戶指定         | `[ASSUMED]` 我方標準 | 指定品牌 +C | 客戶指定會影響設計工時與交期 |
| O3  | 視覺檢測               | 無 / 有                     | 已確認：有    | +D               |                            |
| O4  | 電源規格               | 依出口地區                  | `[需澄清]`    | 變壓器 +E        | 電壓 / 頻率需客戶書面確認  |
| O5  | 安規目標市場           | 台灣 / 歐盟 / 其他          | `[需澄清]`    | 文件與設計 +F    | 需安規工程師確認適用法規   |
| O6  | 文件語言               | 中文 / 英文 / 其他          | `[ASSUMED]` 英文 | 翻譯 +G       |                            |

## 2. 成本結構

### 2.1 設計工時

依「沿用既有設計 vs 新設計」比例分層估算：

```
設計工時（範例）= Σ 模組 [ 基準工時 × 新設計係數 ]
  新設計係數（範例）：沿用 0.1–0.2、修改 0.4–0.6、全新 1.0
  分項：機構設計 / 電控設計 / PLC・HMI・軟體 / 安規文件（風險評估、技術文件）/ 專案管理
設計成本 = 設計工時 × 工程費率（範例：每小時 NT$ X，依公司實績）
```

### 2.2 外購件

| 類別                 | 例子（通用名稱）                       | 估算來源                    | 注意                         |
| -------------------- | -------------------------------------- | --------------------------- | ---------------------------- |
| 長交期件             | 控制器、伺服 / 驅動、減速機、大型鑄件 | 供應商報價（標註報價日期）  | 交期決定專案交期；報價有效期 |
| 標準件               | 線軌、氣壓元件、感測器、電控箱元件     | 歷史採購價 + 漲幅           | 量大時用清單估               |
| 客戶指定品牌件       | 依客戶規範                             | 供應商報價                  | 可能有最低訂購量、較長交期   |
| 外幣計價件           | 進口零組件                             | 報價幣別 × 匯率基準         | 進匯率條款（§5）             |

### 2.3 自製件（委派 core）

把自製件清單（加工件、焊接件、鈑金件）交 core `quote-specialist`，取得單件成本後彙整。若同時安裝 `cnc-machining` profile，加工件可再交 `cnc-programmer` 確認可行性。

### 2.4 組裝、測試與 FAT

```
組裝配線工時（範例）= 機構組裝 + 配管配線 + 電控箱組立
廠內調機 / 空車測試 / 試料
FAT：準備 + 客戶見證天數 + 試料與耗材（範例：見證 2–3 天）
```

### 2.5 現場與交機（最常漏報 — 見 [`eto-vs-mts-quoting`](../know-how/eto-vs-mts-quoting.md)）

| 項目             | 估算方式（範例）                                         |
| ---------------- | -------------------------------------------------------- |
| 包裝             | 木箱 / 防鏽 / 防潮；拆機分箱的工時                       |
| 運輸與保險       | 依 [INCOTERMS 2020](../../../core/know-how/incoterms.md) 條款切分；寫明條款與地點 |
| 安裝試車（SAT）  | 人數 × 人天 × 人天費率 + 差旅住宿 + 吊裝（如由我方負責） |
| 訓練             | 操作 / 維護 / 程式訓練各幾天、在哪裡                     |
| 文件             | 手冊、圖面、翻譯、技術文件、符合性文件                   |
| 隨機備品與耗材   | 依建議備品清單（見 [`project-handover-and-after-sales`](../know-how/project-handover-and-after-sales.md)） |
| 保固準備金       | 成本的 X%（範例 1–3%，依歷史保固支出）                   |
| 第三方認證 / 檢測 | 若客戶或法規要求；適用與否需安規工程師確認              |

## 3. 風險加成（明列）

| 風險因子（範例）                 | 加成（範例） | 理由寫法                         |
| -------------------------------- | ------------ | -------------------------------- |
| 新設計比例 > 50%                 | +5–10%       | 「全新上下料模組，無既有設計」   |
| 首次出口某市場 / 新安規要求      | +3–5%        | 「首次需準備該市場技術文件」     |
| 客戶規範嚴格 / 高安規客製專案   | +3–8%        | 「客戶技術規範 N 頁，含額外驗證」 |
| 驗收標準以客戶產品性能為準       | +3–5%        | 「節拍驗收依客戶工件，未試作」   |
| 交期壓縮                         | +5–10%       | 「需加班 / 外包設計」            |

加成**不藏在毛利裡**；內部報價審查單上逐項列出。

## 4. 假設清單與未定規格清單

每份報價最少包含以下類別（沒有就寫「無」，不要省略標題）：

```
[ASSUMED] 公用設施：電壓 / 頻率 / 氣壓 / 冷卻水由客戶提供至機台 1 m 內
[ASSUMED] 地基、樓板載重、吊裝、搬入路徑由客戶負責
[ASSUMED] 驗收工件由客戶免費提供 N 件（範例）
[ASSUMED] 現場等待（非我方原因）超過 N 天另計
[需澄清] 上下料方式（O1）
[需澄清] 目標市場與適用安全法規（O5）— 需安規工程師確認
[需澄清] 節拍驗收的工件、條件與計算方式
```

---

## 5. 報價有效期、匯率與付款條款（範例條文 — 以公司法務審定版為準）

- **有效期**：本報價有效 30 天（範例）；外購件價格依供應商報價有效期，較短者另註。
- **匯率條款**：本報價以 1 外幣 = X 新台幣（報價日某銀行即期賣出匯率，範例）為基準；簽約前匯率變動超過 ±3%（範例），雙方重議。
- **原物料條款**（選用）：主要鋼材 / 銅材價格於簽約前變動超過 X%，重議（範例）。
- **付款里程碑**（範例）：簽約訂金 30% / FAT 通過出貨前 60% / SAT 驗收後 10%。比例由主管與業務決定。
- **交期**：自規格凍結且收到訂金之日起算，週數**由專案工程師 / 生管確認後填入**。

## Checklist

- [ ] 報價類型（預算 / 正式 / 變更）已標示，且與規格凍結狀態一致
- [ ] 配置選項表每列都有狀態；相依關係已列
- [ ] 設計工時依沿用 / 修改 / 全新分層，費率為最新版本
- [ ] 長交期件有供應商報價日期與有效期
- [ ] 自製件已交 core `quote-specialist` 並取回單件成本
- [ ] 包裝、運輸（INCOTERMS + 地點）、SAT、訓練、文件、備品、保固、認證都有列（含或不含）
- [ ] 風險加成逐項列出 % 與理由
- [ ] 假設清單與未定規格清單完整
- [ ] 有效期、匯率、付款里程碑條款已列
- [ ] 交期欄未由 AI 自行填寫
- [ ] 開頭標示「工程估算 — 非正式報價，需權責主管核准」

## Anti-patterns

- ❌ 用上一台類似機的總價直接報 — 選配與現場條件可能完全不同
- ❌ 「安裝試車另議」— 等於把成本留給專案吃掉；至少給範例估算與假設
- ❌ 把客戶指定品牌件當成我方標準件估價
- ❌ 只寫總價、不展開 — 變更時無法判斷差額
- ❌ 匯率、有效期條款空白
