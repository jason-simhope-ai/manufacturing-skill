# FAT / SAT 出廠與現場驗收 Skill

> ⚠️ **Alpha**：依設備廠一般驗收實務整理，**未經在職專案 / 現場服務工程師驗證**。測試項目、天數、分級與保固條款都是「範例」，以合約與客戶技術規範為準。電氣安全測試與安全功能驗證的方法與判定由合格的電控 / 安規工程師負責 — **本 skill 只確認紀錄存在，不做安全判定**。所有驗收簽署由客戶與我方權責人員親簽。

由 **project-engineer**（FAT）與 **commissioning-service-coordinator**（SAT）使用。

---

## FAT vs SAT

| 項目     | FAT（Factory Acceptance Test）           | SAT（Site Acceptance Test）                       |
| -------- | ---------------------------------------- | ------------------------------------------------- |
| 地點     | 我方工廠                                 | 客戶現場                                          |
| 目的     | 出貨前確認符合凍結規格；問題在家裡解決 | 安裝後確認在實際條件下符合規格                    |
| 常見綁定 | 出貨款里程碑（範例）                     | 尾款、保固起算（範例）                            |
| 限制     | 公用設施與上下游設備可能是模擬的        | 客戶現場條件、客戶工件、客戶人員                  |

> 驗收標準應在**設計階段**與客戶對齊（[`spec-freeze-and-design-review`](spec-freeze-and-design-review.md) DR3），不是 FAT 前一週才寫。

## A. FAT 檢核表

### A1. 就緒檢查（FAT 前約 1 週，範例）

- [ ] 組裝完成、廠內空車與試料測試已跑過，內部問題清單已關閉或註明
- [ ] 驗收工件 / 試料已到（客戶提供者確認數量）
- [ ] 量具 / 測試儀器在校正有效期內
- [ ] FAT 程序書（客戶已確認版次）、空白紀錄表已備妥
- [ ] 安全功能驗證與電氣安全測試**已由我方工程師完成並有紀錄**（客戶見證時可複驗）

### A2. 文件審查

- [ ] 凍結規格表 vs 實機配置逐項對照
- [ ] 電氣圖、氣壓 / 油壓圖為最新版（與實機一致）
- [ ] 手冊草稿（操作 / 維護）、建議備品清單草稿
- [ ] 風險評估與安全功能清單 — 由安規工程師確認狀態（需驗證項目見 [`machinery-safety-ce-basics`](../know-how/machinery-safety-ce-basics.md)）

### A3. 外觀與機構

- [ ] 外觀、塗裝、銘牌與警告標示位置
- [ ] 主要尺寸、占地與規格一致
- [ ] 護罩、圍籬、維修門安裝完整；無銳邊外露

### A4. 電氣安全（紀錄存在性檢查）

依 IEC 60204-1 的驗證項目類別（現行版次與具體方法需驗證；由電控工程師執行與判定）：

- [ ] 保護接地迴路連續性測試紀錄
- [ ] 絕緣電阻測試紀錄
- [ ] 耐壓測試紀錄（如適用）
- [ ] 殘餘電壓保護確認（如適用）
- [ ] 功能測試（含急停）紀錄

### A5. 安全功能驗證（紀錄存在性檢查）

- [ ] 每個急停按鈕實際觸發 → 停機類別符合設計
- [ ] 每個聯鎖門 / 感應式防護觸發 → 危險動作停止，復歸需人為操作
- [ ] 模式選擇（自動 / 手動 / 維修）與權限
- [ ] 安全功能驗證結果由安規 / 電控工程師簽署（AI 不判定合格）

### A6. 功能與性能

- [ ] 每個功能 / 選配逐項動作確認
- [ ] 節拍 / 產能量測（依凍結表定義的方法與工件）
- [ ] 精度 / 品質：試作工件量測結果
- [ ] 連續運轉測試（範例：連續 N 小時或 N 件，無非預期停機）
- [ ] 異常與警報：典型故障模擬與訊息顯示

### A7. 結論

- [ ] 遺留問題清單（分級見 C 段）
- [ ] 出貨條件：通過 / 有條件通過（A 級問題需在出貨前關閉 — 範例原則）/ 不通過
- [ ] 客戶與我方權責人員簽署（AI 不代簽）

## B. SAT 檢核表

### B1. 現場就緒（出貨前由客戶確認 — 範例清單）

- [ ] 地基 / 樓板載重、水平、錨定方式
- [ ] 搬入路徑、門寬、吊裝設備與吊裝責任歸屬
- [ ] 電源（電壓 / 頻率 / 容量 / 接地）已拉至指定位置
- [ ] 壓縮空氣（壓力 / 流量 / 品質）、冷卻水、排氣 / 集塵
- [ ] 上下游設備與介面訊號準備狀態
- [ ] 客戶端窗口、操作人員、停線時段、現場安全規定（入廠訓練、動火許可）

### B2. 安裝與復機

- [ ] 開箱檢查：運輸損傷、缺件（依裝箱單）— 損傷依 [INCOTERMS](../../../core/know-how/incoterms.md) 風險移轉點與保險處理
- [ ] 定位、調水平、錨定；拆機分箱的重新組立
- [ ] 公用設施接入；相序 / 旋轉方向確認

### B3. 安全再驗證

- [ ] 重新執行 A5 安全功能驗證（運輸與重組後必做 — 範例原則）
- [ ] 現場新增的防護 / 介面安全訊號確認
- [ ] 結果由我方工程師簽署；客戶見證

### B4. 生產試運轉與性能驗收

- [ ] 以客戶工件、客戶條件量測節拍 / 品質
- [ ] 連續運轉（範例：N 個班次）
- [ ] 操作 / 維護訓練完成並有簽到紀錄

### B5. 交機

- [ ] 交機文件包移交（清單見 [`project-handover-and-after-sales`](../know-how/project-handover-and-after-sales.md)）
- [ ] 隨機備品點交
- [ ] SAT 驗收紀錄簽署 → 依合約觸發尾款與保固起算

## C. 遺留問題（punch list）分級 — 範例

| 級別 | 定義（範例）                                         | 處理原則（範例）                         |
| ---- | ---------------------------------------------------- | ---------------------------------------- |
| A    | 安全相關，或無法生產 / 不符合關鍵驗收指標            | 必須關閉才能出貨 / 簽 SAT                |
| B    | 可生產但不符合規格（性能略低、部分功能未完成）      | 可有條件驗收；寫明關閉期限與保留款條件   |
| C    | 外觀、文件修正、改善建議                            | 列入清單，約定期限內關閉                 |

**任何安全相關問題一律列 A 級**，不得以「客戶同意」降級（範例原則 — 以公司程序為準）。

## D. 驗收紀錄格式（草稿）

```
草稿 — 待客戶與我方權責人員簽署
驗收類型：FAT / SAT    專案編號：P-YYYY-NNN（範例）   機台序號：<…>
規格依據：凍結規格表 <版次>    FAT / SAT 程序書 <版次>
日期 / 地點：<…>    出席：客戶 <職稱>、我方 <職稱>
| # | 測試項目 | 方法 / 條件 | 標準 | 結果 | 判定欄（由簽署人填） | 備註 |
遺留問題：| # | 描述 | 級別 | 負責人 | 關閉期限 | 關閉條件 |
結論欄：通過 / 有條件通過 / 不通過（由簽署人勾選）
簽署：客戶 ______  我方 ______  （AI 不代簽、不預填）
```

## E. 保固起算（範例條款 — 以合約為準）

常見寫法（擇一或組合，由業務 / 法務在合約定義）：

1. **自 SAT 驗收簽署日起算** N 個月
2. **自出貨日起算** N 個月，或**自 SAT 驗收日起算** M 個月，**以先到者為準**
3. **視為驗收**：設備到場後非因我方原因，N 天內未能進行 SAT → 視為驗收，保固起算（範例）

同時寫明：保固範圍（材料與工藝瑕疵）、**不含**項目（耗材、易損件、不當使用、未經同意的改造）、現場服務是否含差旅。保固相關解釋一律回到合約，由主管決定。

---

## Anti-patterns

- ❌ FAT 前才寫檢核表 → 客戶在 FAT 現場「新增驗收標準」
- ❌ 有 A 級遺留問題就出貨，期待現場再修
- ❌ 運輸重組後不重做安全功能驗證
- ❌ 驗收紀錄沒有遺留問題清單 → 尾款與保固起算爭議
- ❌ 口頭驗收、事後補簽
