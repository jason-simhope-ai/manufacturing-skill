# 交機與售後服務

> ⚠️ **Alpha**：基於一般實務整理，**未經在職售後主管驗證**。SLA 時間、分級與比例都是「範例」，以合約與公司服務政策為準。AI 不承諾到場時間或修復時間。

由 **commissioning-service-coordinator**、**project-engineer** 與 **eto-quote-engineer**（售後成本報價）使用。

---

## 1. 交機文件包

SAT 時移交；清單應在報價與規格凍結時就與客戶約定（語言、份數、格式）。

| #   | 文件                                   | 備註                                               |
| --- | -------------------------------------- | -------------------------------------------------- |
| 1   | 操作手冊                               | 含安全注意事項、殘餘風險、警告標示說明             |
| 2   | 維護保養手冊                           | 保養項目、週期、潤滑表、LOTO 程序                  |
| 3   | 電氣圖、氣壓 / 油壓圖                  | 竣工版（as-built），與實機一致                     |
| 4   | 機構總圖與易損件圖                     | 範圍依合約（設計圖面所有權常是爭議點）             |
| 5   | 外購件清單與原廠手冊                   | 含供應商料號、規格                                 |
| 6   | 軟體備份                               | PLC / HMI / 機器人程式版本與備份媒體；授權資訊     |
| 7   | 備品清單                               | 隨機備品點交表 + 建議庫存備品清單                  |
| 8   | FAT / SAT 驗收紀錄與遺留問題清單       | 已簽署版本                                         |
| 9   | 符合性文件副本                         | 例：符合性聲明、安全資訊申報資料（依市場，需驗證） |
| 10  | 訓練紀錄                               | 簽到表、訓練內容                                   |
| 11  | 保固條款與服務聯絡窗口                 | 含問題回報方式與升級路徑                           |

## 2. 備品與耗材

| 類別           | 定義                                   | 例子（通用）                   | 誰付費（範例）               |
| -------------- | -------------------------------------- | ------------------------------ | ---------------------------- |
| 隨機備品       | 合約約定隨機附送                       | 保險絲、密封件組、常用感測器   | 含在設備價                   |
| 建議庫存備品   | 故障會停機、交期長的關鍵件             | 驅動器、特殊馬達、客製治具件   | 客戶另購（另報價）           |
| 耗材           | 正常使用會消耗                         | 濾芯、刀具、皮帶、潤滑油       | 客戶，**不在保固內**         |
| 易損件         | 依使用條件磨耗                         | 夾爪、吸盤、導輪               | 依合約；常列為保固除外       |

**建議備品清單的判斷**：停機影響 × 採購交期 × 故障機率。交期長、停機損失大的件，即使便宜也要建議庫存。

## 3. 售後 SLA 範例

> 以下是**範例**，實際以合約與服務政策為準；到場時間取決於地點、簽證、人力 — AI 不承諾。

| 等級 | 定義（範例）                                   | 初步回應（範例） | 遠端診斷（範例） | 到場評估（範例）            |
| ---- | ---------------------------------------------- | ---------------- | ---------------- | --------------------------- |
| P1   | 安全相關，或整線停機                           | 2 小時內         | 當日             | 由服務主管當日決定          |
| P2   | 性能下降、部分功能失效，仍可生產               | 1 個工作日       | 2 個工作日       | 依診斷結果安排              |
| P3   | 一般問題、操作疑問、改善需求                   | 2 個工作日       | 依排程           | 視需要                      |

## 4. 問題升級矩陣（範例）

| 情境                                         | 第一線                 | 升級對象                              | 升級時點（範例）       |
| -------------------------------------------- | ---------------------- | ------------------------------------- | ---------------------- |
| **安全相關**（防護失效、受傷 / 險些受傷）    | 服務協調員             | 服務主管 + 安規 / 設計工程師 + 管理層 | **立即**               |
| P1 停機，遠端無法排除                        | 服務工程師             | 服務主管 → PM / 設計主管              | 遠端診斷超過 N 小時    |
| 同一問題重複發生（範例：30 天內 ≥ 2 次）    | 服務協調員             | 設計團隊（8D / ECR）                  | 第 2 次發生            |
| 備品交期影響停機                             | 服務協調員             | 採購 + 服務主管                       | 交期超過客戶容忍       |
| 保固範圍爭議                                 | 服務協調員             | 服務主管 + 業務                       | 客戶提出即升級         |
| 客戶要求改造 / 加功能                        | 服務協調員             | 報價工程師 + 專案工程師               | 視為新案，走報價流程   |

客戶自行改造後發生的問題，要特別記錄改造內容 — 可能影響保固與原有的符合性（改造的法規定義需驗證）。
