# 機械安全與 CE 基礎

> ⚠️ **Alpha — 這不是安全評估，也不是法規意見。**
> 本文是讓報價、專案、售後人員「知道要問什麼」的導讀。法規條號、標準版次、過渡期、指定品項與申報程序**一律需驗證**，以官方公報、主管機關現行公告與標準原文為準。風險評估、安全功能設計與驗證、符合性聲明與 CE 標示，由製造商的權責工程師負責並簽署。

由 **eto-quote-engineer**（報價時知道安規影響範圍）、**project-engineer**（確認流程有人負責）、**commissioning-service-coordinator**（現場安全問題升級）使用。

## 1. 風險評估流程（ISO 12100 架構）

```
1. 決定機械的限制（使用限制、空間限制、時間限制）— 含可合理預見的誤用
2. 危害辨識（機械性、電氣、熱、噪音、振動、輻射、材料 / 物質、人因、環境…）
   — 涵蓋生命週期：運輸、安裝、試車、使用、清潔、維修、拆除
3. 風險估計（傷害嚴重度 × 發生機率：暴露頻率、危險事件機率、避免可能性）
4. 風險評價（是否需要降低風險）
5. 風險降低 — 三步法，依序：
   ① 本質安全設計（消除危害或降低到不需防護）
   ② 安全防護與補充保護措施（護罩、聯鎖、感應式防護、急停…）
   ③ 使用資訊（警告標示、手冊、訓練要求）
→ 回到 2，直到風險被評價為可接受；全程留紀錄
```

**重點**：不能用「手冊寫注意」取代可行的設計或防護（三步法的順序）。

## 2. 安全功能常見類型

| 類型                   | 例子（通用）                           | 相關標準（需驗證）                 |
| ---------------------- | -------------------------------------- | ---------------------------------- |
| 急停                   | 急停按鈕 / 拉繩                        | ISO 13850、IEC 60204-1             |
| 聯鎖防護               | 維修門開啟 → 危險動作停止              | ISO 14119                          |
| 感應式防護             | 光幕、區域掃描器、安全地墊             | IEC 61496 系列、ISO 13855（安全距離） |
| 防止意外啟動           | 上鎖掛牌（LOTO）點、能量隔離           | ISO 14118                          |
| 安全速度 / 安全停止    | 手動模式降速、安全停止監控             | IEC 61800-5-2 等                   |
| 雙手操作               | 沖壓類設備                             | ISO 13851                          |
| 固定 / 可動護罩        | 傳動件、刀具區                         | ISO 14120、ISO 13857（安全距離）   |

控制系統安全相關部分的可靠度用 **ISO 13849-1（PL a–e）** 或 **IEC 62061（SIL）** 表達；要求的 PL / SIL 由風險評估決定 — **由安規 / 設計工程師計算與驗證**。

電氣設備安全以 **IEC 60204-1** 為基礎（電源切斷裝置、保護接地、絕緣、控制電路、急停停機類別、驗證測試等）。

## 3. CE 標示（歐盟市場）— 需驗證

| 項目               | 機械指令 2006/42/EC                        | 機械法規 (EU) 2023/1230                                       |
| ------------------ | ------------------------------------------ | ------------------------------------------------------------- |
| 法律形式           | 指令（各會員國轉換為國內法）               | 法規（直接適用）                                              |
| 適用時間           | 現行                                       | 取代 2006/42/EC；**一般適用日期與過渡安排需驗證**（公開資訊為 2027 年 1 月起） |
| 高風險機械         | 附件 IV 清單                               | 附件 I（分 A / B 部分）— 部分類別須第三方符合性評鑑（需驗證） |
| 新增重點（摘要）   | —                                          | 數位化使用說明的條件、含 AI / 自主行為與網路安全相關的安全要求、實質改造的定義（需驗證） |

**CE 技術文件的常見組成**（依 2006/42/EC 附件 VII A 架構整理，2023/1230 對應附件需驗證）：

- [ ] 機械的一般描述、總圖、控制電路圖及理解運作所需的說明
- [ ] 確認符合基本健康與安全要求所需的詳細圖面、計算、測試結果
- [ ] **風險評估文件**：適用的基本要求清單、為消除危害或降低風險所採取的措施、殘餘風險
- [ ] 採用的調和標準與其他技術規範清單
- [ ] 測試報告（自行或第三方）
- [ ] 使用說明書（目標國語言要求需驗證）
- [ ] 部分完成機械：組裝說明書與合併聲明（declaration of incorporation）
- [ ] 符合性聲明（Declaration of Conformity）副本
- [ ] 量產品：確保持續符合的內部措施
- [ ] 保存期限（2006/42/EC 為最後製造日起至少 10 年 — 需驗證）

**其他可能同時適用的歐盟法規**（依機型，需驗證）：EMC 指令 2014/30/EU、壓力設備、ATEX（防爆）、RoHS 等。低電壓指令與機械指令的關係需依機型判斷。

> 「部分完成機械」（partly completed machinery）與「整機」的義務不同 — 自動化設備常是整合進客戶產線的模組，**哪一方負責整線的符合性要在報價與合約階段講清楚**。

## 4. 台灣：機械設備器具安全 — 需驗證

依 **職業安全衛生法** 相關條文（條號與子法需驗證）：

- 中央主管機關**指定**之機械、設備或器具，其構造、性能及防護須符合**安全標準**（如「機械設備器具安全標準」），才能產製運出廠場、輸入、租賃、供應或設置。
- 製造者或輸入者須在**資訊申報網站登錄**（俗稱「安全資訊申報」），並於產品明顯處張貼**安全標示**；部分品項另需**型式驗證**。
- 指定品項範例（**以勞動部職業安全衛生署現行公告為準**）：動力衝剪機械、手推刨床、木材加工用圓盤鋸、研磨機、研磨輪、防爆電氣設備、動力堆高機等。

**對設備廠的實務提醒**：

- 報價時就要問「機器是否屬於公告指定品項」— 影響設計（防護裝置）、測試與申報成本與時程
- 申報資料（符合性聲明、測試報告等）的準備由權責工程師負責
- 出口機台以目的地法規為主；台灣內銷與進口機台要看台灣規定

## 5. 高安規客製專案

部分客戶（例如對安全、潔淨、可靠度有特殊要求的產業）會有**自己的技術規範**：指定安全元件等級、指定文件格式、額外的驗證與稽核。原則：

- 客戶規範**加在**法規之上，不取代法規
- 報價時列入「客戶規範 N 頁」與因應成本；規範改版 = 重報價觸發條件（見 [`spec-freeze-and-design-review`](../skills/spec-freeze-and-design-review.md)）
- 規範條文是客戶機密 — 不要貼進公開環境；先去識別化
