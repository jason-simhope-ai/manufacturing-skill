# ETO 與量產報價的差異

> ⚠️ **Alpha**：本文是 agent 操作參考用的精華版，基於一般實務整理，**未經在職設備廠報價工程師驗證**。所有比例與數字都是「範例」。

由 **eto-quote-engineer** 與 **project-engineer** 使用。

---

## 四種接單模式

| 模式                         | 縮寫 | 典型產品                         | 報價看什麼                         |
| ---------------------------- | ---- | -------------------------------- | ---------------------------------- |
| Make-to-Stock 存貨生產       | MTS  | 標準件、目錄品                   | 價目表                             |
| Make-to-Order 接單生產       | MTO  | 客戶圖紙零件（CNC、射出、鈑金） | 圖紙 → 材料 + 工時（core 報價）    |
| Configure-to-Order 接單組態  | CTO  | 標準機 + 選配                    | 基本機價 + 選配價                  |
| Engineer-to-Order 接單設計   | ETO  | 特殊機、自動化產線、改造         | 規格 → 設計 + 採購 + 現場 + 風險  |

實務上一台設備常是混合：**基本機是 CTO，客製模組是 ETO，裡面的零件是 MTO**。這就是本 profile 與 core [`quote-specialist`](../../../core/agents/quote-specialist.md) 分工的原因。

## ETO 報價和量產（零件）報價差在哪

| 面向         | 量產 / 零件報價                     | ETO 整機報價                                         |
| ------------ | ----------------------------------- | ---------------------------------------------------- |
| 輸入         | 圖紙、BOM、數量                     | 需求規格（URS）、技術協議、選配表 — 常常不完整     |
| 成本主體     | 材料 + 機台工時                     | 設計工時 + 外購件 + 組裝 + 現場服務                  |
| 數量         | 數百到數萬件，攤提 setup            | 通常 1 台或少量；設計成本不攤提                      |
| 不確定性     | 低（重複生產有實績）                | 高（新設計、客戶規格會變、現場條件未知）            |
| 交期驅動     | 產能與排程                          | 長交期件 + 設計時間 + 客戶確認速度                   |
| 驗收         | 尺寸 / 外觀檢驗                     | FAT / SAT、性能驗收、文件與訓練                      |
| 付款         | 出貨後月結                          | 里程碑（訂金 / 出貨 / 驗收 — 範例）                  |
| 報價後的變化 | 少                                  | 規格凍結前後都可能變 → 需要重報價機制               |
| 售後         | 品質客訴                            | 保固、備品、現場服務、遠端支援，常延續數年          |

## 常見漏報項 Top 10

報價審查時，**每一項都要在報價上出現**（含或不含都要寫）：

| #   | 漏報項                     | 常見後果                                                  | 報價寫法（範例）                                       |
| --- | -------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| 1   | 運輸與保險                 | 海運費、內陸運輸、吊裝費全由專案吸收                      | 寫明 INCOTERMS 2020 條款 + 地點（見 core [`incoterms`](../../../core/know-how/incoterms.md)） |
| 2   | 安裝試車人天與差旅         | 現場拖延 → 人天爆量                                       | 含 N 人 × N 天；超過部分依人天費率計                   |
| 3   | 現場等待                   | 客戶現場未就緒，工程師乾等                                | 非我方原因等待超過 N 天另計                            |
| 4   | 訓練                       | 客戶要求多次、多地點訓練                                  | 含操作 / 維護訓練各 N 天，地點 <…>                     |
| 5   | 文件與翻譯                 | 多語手冊、技術文件、客戶格式文件                          | 文件清單與語言列入報價                                 |
| 6   | 備品與耗材                 | 客戶以為隨機附整套備品                                    | 隨機備品清單附件；建議備品另報                         |
| 7   | 匯率與原物料               | 進口件與鋼材價格變動吃掉毛利                              | 匯率基準 + 變動門檻條款                                |
| 8   | 保固範圍與起算             | 驗收拖延 → 保固無限延後；耗材被當保固                     | 起算條件 + 不含項目（見 [`fat-sat-acceptance`](../skills/fat-sat-acceptance.md)） |
| 9   | 安規文件與認證             | 出口市場需技術文件、第三方檢測                            | 目標市場與文件範圍列入；適用法規需安規工程師確認       |
| 10  | 專案管理與客戶會議         | 多次設計審查、客戶到廠、FAT 重測                          | FAT 含 N 次；重測因客戶變更者另計                      |

其他常被忽略：電源規格轉換（變壓器）、客戶指定品牌件、軟體授權、遠端連線設備、包裝防鏽、拆機重組工時、FAT 用試料、保留款。

## 選配報價的三個原則

1. **選配要有相依表**：選了機械手臂上下料，連帶要防護圍籬、安全功能、風險評估更新、FAT 時間。
2. **「標準配置」要白紙黑字**：客戶認知的標準和我方的標準常常不一樣，寫成清單。
3. **刪除選配不等於原價扣回**：設計已投入、外購件已下單的部分要另計。

## 預算報價 vs 正式報價

| 項目     | 預算報價                                | 正式報價                         |
| -------- | --------------------------------------- | -------------------------------- |
| 前提     | 規格未凍結                              | 規格凍結、選配全部確認           |
| 精度     | 範圍（範例 ±20–30%）                    | 單一金額 + 條款                  |
| 用途     | 客戶編預算、內部決定要不要投標          | 簽約依據                         |
| 標示     | `[預算報價]`，寫明「規格凍結後重報」    | 正式報價編號                     |

把預算報價當正式報價簽約，是 ETO 專案虧損最常見的起點之一。

---

## 報價後檢討（quote-vs-actual）

結案時比較：設計工時、外購件、現場人天、保固支出 — 報價 vs 實際。把差異回饋到下次報價的係數（新設計係數、人天費率、保固準備金比例）。沒有這個迴圈，報價係數永遠是猜的。
