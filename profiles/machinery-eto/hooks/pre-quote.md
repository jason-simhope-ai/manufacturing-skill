# pre-quote Hook（設備 ETO 版）

> ⚠️ **Alpha**：此 hook 取代 core 的 [`pre-quote`](../../../core/hooks/pre-quote.md)。**core 的零件級圖紙檢查原封保留在 B 段**；本版只在前面加上整機（ETO）報價的閘門。AI 只檢查資訊是否齊備，不決定價格、不承諾交期，也不判定適用哪些安全法規。

在 `quote-specialist`（零件）或 `eto-quote-engineer`（整機）開始算錢之前先擋一關。資料不齊就**強制中止報價，回問**。

---

## 0. 分流

| 詢價內容                                         | 走哪段       | 報價者                                                                     |
| ------------------------------------------------ | ------------ | -------------------------------------------------------------------------- |
| 單一零件 / 備品零件 / 有圖紙的加工件             | **B 段**     | core [`quote-specialist`](../../../core/agents/quote-specialist.md)        |
| 整機、產線、自動化工作站、改造（retrofit）       | **A 段**     | [`eto-quote-engineer`](../agents/eto-quote-engineer.md)                    |
| 整機內的自製件清單                               | A 段通過後，逐件走 B 段 | core `quote-specialist` 算單件，`eto-quote-engineer` 彙整   |

> 多 profile 安裝時（例：同時裝 `cnc-machining`），零件詢價一律走 B 段，行為與 core 相同。

---

## A. 整機（ETO）閘門

### A1. 規格凍結閘門

- [ ] 有書面需求規格（URS / 技術協議 / 規格書），並註明版次
- [ ] **規格已凍結**（客戶書面確認）— **未凍結 → 不得出正式報價**，只能出標 `[預算報價]` 的範圍估算，並寫明「規格凍結後重報」
- [ ] 若為變更追加報價：引用原報價編號與變更單（ECR）編號

### A2. 選配狀態

- [ ] 配置選項表**每一項**都有狀態：已確認 / `[ASSUMED]` / `[需澄清]`
- [ ] **未定選配一律標 `[需澄清]`**，不得默默以「標準配置」帶過
- [ ] 選配相依關係已列（例：自動上下料 → 防護圍籬、安全功能、風險評估更新）

### A3. 商務與現場條件

- [ ] 出口地區 / 安裝地點，以及**目標市場的安全規範要求**（例：CE、台灣安全資訊申報、客戶自有安全規範）— 適用與否標「需安規工程師確認」
- [ ] 公用設施：電壓 / 頻率 / 接地、氣壓、冷卻水
- [ ] 交貨條件：INCOTERMS 2020 條款 + 地點（見 core [`incoterms`](../../../core/know-how/incoterms.md)）
- [ ] 安裝試車（SAT）、訓練、文件語言的範圍
- [ ] 驗收標準（FAT / SAT 項目與性能指標的量測方法）
- [ ] 報價幣別與匯率基準
- [ ] 客戶要求交期（**AI 不承諾，交期由專案工程師 / 生管確認**）

---

## B. 零件圖紙完整度（core 原有檢查，保留）

對 input 圖紙與 RFQ：

- [ ] 圖紙檔案能讀（PDF / DWG / STEP / 圖片）
- [ ] 件名 / 件號明確
- [ ] 材料牌號明確（不是「不鏽鋼」這種模糊描述，要 SUS304 / SUS316L 等）
- [ ] 主要尺寸有公差（不是只標稱尺寸）
- [ ] 表面粗糙度標註（Ra 值）
- [ ] 表面處理規範（如有：陽極厚度、電鍍規範、塗裝色號）
- [ ] 熱處理要求（如有：硬度範圍 HRC、HV）
- [ ] 數量
- [ ] 客戶要求交期
- [ ] 付款條件（如已知）

## 失敗處理

### 整機（A 段）缺項

```
🛑 整機正式報價暫停 — 工程估算閘門未通過：
- 規格未凍結（URS v0.3 草稿，客戶尚未書面確認）→ 僅可出 [預算報價]
- 選配 O1 上下料方式：[需澄清]
- 目標市場與安全規範未知 → 需安規工程師確認
- 驗收節拍的量測方法未定義

請業務 / 專案工程師回客戶確認後再啟動正式報價。
```

### 零件（B 段）缺項（同 core）

```
🛑 報價暫停 — 缺少必要資訊：
- 材料牌號未指定（圖紙僅標「不鏽鋼」）
- φ20 公差未標註
- 表面處理規範缺
- 數量未確認

請業助回客戶 / 工程確認後再啟動報價。
```

不要在資料不全時硬報。

---

## 例外通行

只有在以下情況可繞過（必須記錄理由）：

- 客戶明確要求「給粗估範圍」（零件標 [ROUGH ESTIMATE]、整機標 [預算報價]，不當正式報價）
- 內部試算用（不會送出客戶）

**不可繞過**：整機正式報價的 A1「規格已凍結」— 未凍結只能出預算報價。
