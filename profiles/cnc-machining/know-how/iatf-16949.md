# IATF 16949 汽車品質管理體系

> 汽車產業客戶（OEM、Tier 1、Tier 2）強制要求的品質體系。
> 比 ISO 9001 嚴格很多。

---

## 與 ISO 9001 的關係

```
IATF 16949 = ISO 9001 + 汽車產業特定要求
```

所以拿 IATF 16949 證 = 自動含 ISO 9001。

---

## 5 個核心工具（Core Tools）

| 工具     | 全名                              | 用途                          |
| -------- | --------------------------------- | ----------------------------- |
| **APQP** | Advanced Product Quality Planning | 產品開發階段品質規劃          |
| **PPAP** | Production Part Approval Process  | 量產件批准（送樣 + 文件）     |
| **FMEA** | Failure Mode and Effects Analysis | 失效模式分析（DFMEA + PFMEA） |
| **MSA**  | Measurement System Analysis       | 量測系統分析（GR&R）          |
| **SPC**  | Statistical Process Control       | 統計製程管制                  |

---

## PPAP 5 等級

| Level | 文件               | 樣品          |
| ----- | ------------------ | ------------- |
| 1     | 部分文件 + 簽呈    | 不送          |
| 2     | 部分文件           | 少量送        |
| 3     | **完整 PPAP 文件** | 送 + 客戶測試 |
| 4     | 客戶指定文件       | 客戶決定      |
| 5     | 內部審核           | 內部          |

最常用：**Level 3**。

PPAP Level 3 文件清單（18 項）：

1. Design Records（圖紙）
2. ECN（工程變更通知）
3. Customer Engineering Approval
4. DFMEA
5. Process Flow Diagram
6. PFMEA
7. Control Plan
8. MSA Studies (GR&R)
9. Dimensional Results (FAI)
10. Material / Performance Test Results
11. Initial Process Studies (Cpk ≥ 1.67)
12. Qualified Laboratory Documentation
13. Appearance Approval Report
14. Sample Production Parts
15. Master Sample
16. Checking Aids
17. Customer-Specific Requirements
18. PSW (Part Submission Warrant) — 蓋章送出的封面

---

## FAI (First Article Inspection)

首件全尺寸量測報告，PPAP 第 9 項。

對件上每一個尺寸（含公差、表面粗糙度、形位公差）都要量並記錄：

```
FAI Report
件號：BR-12345 rev2
工單：W2026042100123
量測日期：2026-04-21
量測員：張三
量測工具：CMM ABC-001（校驗有效期 2026-12）

| Item | 規範 | 實測 | 偏差 | OK/NG |
| 1    | 50.00 ± 0.05  | 50.012 | +0.012 | OK |
| 2    | φ20H7 | φ19.992 | -0.008 | OK |
...
```

---

## Run @ Rate

量產驗證：在量產條件下連續做 X 件（通常 300 件 / 8 小時），證明製程穩定且良率達標。

---

## Cpk 要求

汽車件量產：Cpk ≥ 1.67（製程能力卓越）。
比一般 ISO 9001 的 Cpk ≥ 1.33 嚴。

---

## 對 agent 的硬要求

當客戶為汽車業時：

- `quote-specialist` 要把 PPAP 文件成本算進報價
- `prototype-coordinator` 必走 PPAP 流程
- `quality-inspector` 用 IATF 嚴格版檢驗（Cpk 1.67、FAI 全尺寸）
- 所有 record 都要可追溯到 SO + WO + 操作員 + 機台 + 刀具批號

---

## 常見誤解

- ❌「拿到 IATF 證就無敵」→ 客戶仍會做 process audit
- ❌「PPAP 給一次就好」→ 任何變更（圖紙、機台、供應商、地點）都要重提
- ❌「Cpk 高就 OK」→ 還要看 stability、capability index 對溫度等是否敏感
