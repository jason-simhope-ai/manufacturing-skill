# 刀具壽命管理

由 **tool-life-engineer** 主導使用。

---

## Taylor's Tool Life Equation

```
v × T^n = C
v：切削速度 (m/min)
T：刀具壽命 (min)
n：材料 / 刀具常數
C：常數
```

從 Taylor 公式可導：**速度提高 1 倍 → 壽命降低數倍**。

| 刀具 | n 值範圍 |
|---|---|
| 高速鋼 HSS | 0.08 ~ 0.20 |
| 鎢鋼 | 0.20 ~ 0.40 |
| 陶瓷 | 0.40 ~ 0.60 |
| 立方氮化硼 (CBN) | 0.60 ~ 1.00 |

n 越小 = 速度敏感性越高。

## 壽命量測指標

| 指標 | 意義 | 何時用 |
|---|---|---|
| 切削時間 | 累計切削分鐘 | 一般用 |
| 切削長度 | 累計刀刃通過工件距離 | 不同件混做時 |
| 加工件數 | 累計加工件數 | 同件批量時最直觀 |
| VB | 刀面磨耗量 (mm) | 精密量測 |

## 換刀策略

### 1. 預防性換刀（Preventive Replacement）

```
換刀時機 = 預估壽命 × 80~90%
```

優：可控、不會突然斷
缺：可能換太早浪費

### 2. 條件性換刀（Condition-based）

監測 VB 量、切削力、聲音、振動，達閾值才換。

優：用到極限、最省刀
缺：需要監測設備、可能突然壞

### 3. 反應性換刀（Reactive）

斷了 / 不良才換。

❌ **不要做**。意外後果（不良品 + 停線 + 重做）成本遠高於省下的刀錢。

## 各類刀具典型壽命（精華版）

| 刀具 | 材料 | 典型壽命 |
|---|---|---|
| 平銑刀 D8 鎢鋼 | 鋁合金 | 200~400 件（小件） |
| 平銑刀 D8 鎢鋼 TiAlN | 不鏽鋼 304 | 60~100 件 |
| 鑽頭 φ6 HSS | 軟鋼 | 100~300 孔 |
| 鑽頭 φ6 鎢鋼 | 不鏽鋼 304 | 50~150 孔 |
| 螺絲攻 M6 HSS | 軟鋼 | 200~500 孔 |
| 螺絲攻 M6 HSS | 不鏽鋼 | 50~150 孔 |
| 球頭 R3 鎢鋼 | 模具鋼 (HRC50) | 100~300 件 |

實際壽命受切削參數、冷卻、機台剛性影響很大，**請以實測為準**。

## 換刀紀錄

每次換刀必填：

```
日期、機台、工單、刀具型號、新舊刀
換刀原因：到壽 / 異常磨耗 / 斷刀 / 預防性 / 其他
本次累計：時間 / 件數 / 長度
觀察：磨耗形式（VB / 月牙窪 / 崩刃）
```

→ 累積數據，定期回去校正預估壽命。

---

## 刀具回收

- 鎢鋼刀：報廢時收集，賣給回收商有殘值（NT$200~500/kg）
- 高速鋼：殘值低，但量大也值得收集
- 陶瓷：通常無殘值

---

## Anti-patterns

- ❌ 反應性換刀（斷了再換）
- ❌ 為延刀壽降速度（連帶 cycle time 變長）
- ❌ 不分材料 / 機台用同一壽命標準
- ❌ 不記錄換刀原因 → 無法找根因
