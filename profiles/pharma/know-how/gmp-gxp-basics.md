# GMP / GxP 基礎

## GxP 是什麼

GxP = 一群「Good ___ Practice」：GMP（製造）、GLP（非臨床實驗室）、GCP（臨床試驗）、GDP（運銷 — 注意與 Good Documentation Practice 同縮寫）。本 profile 只處理 **GMP**，以及醫材的 **ISO 13485 / QMS**。

| 產品                | 主要框架（範例，適用性需驗證）                                              |
| ------------------- | --------------------------------------------------------------------------- |
| 原料藥（API）       | ICH Q7、PIC/S GMP Part II                                                   |
| 製劑                | PIC/S GMP Part I + Annexes；外銷美國另有 21 CFR 210 / 211                   |
| 無菌製劑            | 上述 + Annex 1（污染管制策略 CCS、環境監測）                                |
| 醫療器材            | ISO 13485；台灣「醫療器材品質管理系統準則」；美國 21 CFR 820（QMSR）        |
| 共通                | ICH Q9(R1) 風險管理、ICH Q10 品質系統、21 CFR Part 11 / Annex 11 電子紀錄 |

台灣：西藥製造自 2015 年起全面實施 PIC/S GMP（時程與適用範圍需驗證），主管機關為衛福部食藥署（TFDA）。

## GMP 的支柱（ICH Q10 品質系統要素）

1. **製程績效與產品品質監控** — 趨勢、APR / PQR（年度產品品質檢討）
2. **CAPA 系統** — 偏差、OOS、投訴、稽核發現 → 根因 → 矯正 / 預防 → 有效性確認
3. **變更管理** — 任何影響品質的變更先評估、核准再實施（見 [`validation-and-change-control`](validation-and-change-control.md)）
4. **管理審查** — 高層定期審視品質系統績效

加上兩個推動力：**知識管理** 與 **品質風險管理（ICH Q9(R1)）** — 風險管理的努力程度與文件化程度要和風險相稱，且要減少主觀性。

其他常見支柱：人員資格與訓練、廠房設施與設備（確效 / 校正 / 保養）、物料管理與供應商資格、文件管理、品質管制實驗室、委外作業管理、自我查核。

## 文件層級

```
        ┌──────────────────────────┐
        │ 品質手冊 / 品質政策        │
        ├──────────────────────────┤
        │ 程序書（SOP）              │  偏差、CAPA、變更、文件管理…
        ├──────────────────────────┤
        │ 主文件：規格、MBR、檢驗方法 │  經核准、受控、有版次
        ├──────────────────────────┤
        │ 紀錄：批次紀錄、檢驗紀錄、  │  執行的證據 = GMP 紀錄
        │ 日誌、偏差 / CAPA 報告      │
        └──────────────────────────┘
```

與 core [`iso-9001`](../../../core/know-how/iso-9001.md) 金字塔同構，差別在於 GMP 對**紀錄的可信度**要求更嚴（資料完整性）。

**AI 產出放在哪一層？哪一層都不是。** AI 草稿最多是「起草參考」，進入任何一層前都要由權責人員以受控方式重新產出、審核、簽署。

### 良好文件規範（GDP）重點

- 當下記錄、不可預填；不可擦除筆；不用鉛筆、修正液、便利貼
- 更正：單線劃除、原值可讀、寫理由、簽名日期
- 不適用：劃 N/A 並簽名，不留白
- 簽名代表「我做了 / 我覆核了」— 不可代簽、不可事後補簽而不註明

## 偏差 vs OOS vs OOT

| 類別          | 定義                                                   | 典型例子                            | 走什麼程序             |
| ------------- | ------------------------------------------------------ | ----------------------------------- | ---------------------- |
| **偏差**      | 偏離已核准的程序、指令、規格或標準                     | 混合時間少 5 分鐘、潔淨區壓差異常   | 偏差程序 → 調查 → CAPA |
| **OOS**       | 檢驗結果**超出**已核准的規格或允收標準                 | 含量 92.0%，規格 95.0–105.0%（範例） | OOS 程序：先實驗室調查（Phase I），無明確實驗室錯誤則擴大到製程調查（Phase II） |
| **OOT**       | 結果**仍在規格內**，但偏離歷史趨勢或預期               | 穩定性第 12 月不純物明顯跳升但未超標 | 趨勢程序 → 評估 → 視需要升級為偏差 |

- OOS 不能靠「重測到合格」解決；原始 OOS 結果要有可證明的實驗室根因才能判無效 — **判定由 QA / QC 主管，不是 AI**
- 偏差常見分級：Critical / Major / Minor（定義依公司程序書；分級由 QA 決定）
- 計畫性偏差（planned deviation）在多數公司需**事前**經 QA 核准，有些公司要求改走變更管制（依程序書，需驗證）

## 資料完整性 — ALCOA+

| 字母 | 原則            | 一句話                                   |
| ---- | --------------- | ---------------------------------------- |
| A    | Attributable    | 誰、何時做的，看得出來                   |
| L    | Legible         | 讀得懂，且長期可讀                       |
| C    | Contemporaneous | 發生當下記錄                             |
| O    | Original        | 原始紀錄或經確認的真實副本               |
| A    | Accurate        | 正確、無錯誤、修改有紀錄                 |
| +    | Complete        | 全部資料（含重測、失敗、刪除）都在       |
| +    | Consistent      | 時序、格式一致                           |
| +    | Enduring        | 在保存期間內不會消失                     |
| +    | Available       | 需要時（審查、稽核）可取得               |

部分指引另提 **ALCOA++**（加 Traceable 等），名稱與範圍依指引版本（需驗證）。

**電子紀錄**（21 CFR Part 11 / Annex 11）：系統確效、個人帳號與權限、audit trail 開啟且定期審查、電子簽章與身分綁定、備份與還原測試。共用試算表檔通常**不**符合這些要求。

**紀錄保存年限**：藥品常見要求為效期後至少 1 年，或依地區另有更長年限（例如 EU 以放行後年數計）；醫材依產品壽命與法規 — **具體年限需驗證**。

## 稽核 / 查核常見缺失（自我檢查用）

1. **資料完整性**：共用帳號、audit trail 關閉或從未審查、「試打」注射不保留、刪除數據
2. **調查不足**：根因停在「人為疏失」，CAPA 只有再訓練；影響評估只看本批
3. **OOS 處理**：無可證明根因即判無效、重測直到合格
4. **CAPA 無效**：同類偏差重複發生；有效性確認未事先定義標準
5. **變更管制被繞過**：先改後補單、未評估確效影響、未評估法規申報影響
6. **確效缺口**：設備 / 電腦化系統未確效或確效後重大變更未再評估；清潔確效最差情況選擇無理由
7. **批次紀錄**：漏簽、事後補記、列印報表未附、更正不合 GDP
8. **訓練**：人員在受訓前就執行該 SOP；SOP 改版後未再訓練
9. **供應商管理**：關鍵原料供應商未稽核或資格過期
10. **APR / PQR** 只有數據沒有結論與行動

## AI 在這裡的界線

- ✅ 整理事實、起草調查架構與 CAPA 草稿、做完整性預檢、用白話解釋法規概念、出訓練題目
- ❌ 結案偏差、核准 CAPA、判定 OOS 無效、放行批次、決定法規申報類別或通報
- ❌ 產出、修改或取代任何 GMP 紀錄；AI 輸出一律標 `AI-DRAFT — 非 GMP 紀錄`
- ❌ 當作法規最終解釋 — 疑義請洽主管機關、法規事務或顧問
