# 建議起始 denylist（starter）— 通用字詞，不含任何公司、客戶或專案名稱。
#
# 用法：複製到本機名單後，再加上貴公司自己的客戶名、客戶代號、圖號與專案代號樣式：
#   cat team/tools/denylist.starter.txt >> team/local/names.denylist
# gateway（輸入 DLP 與輸出過濾）、deid.py 與 pre-commit-names hook 都讀同一份檔。
#
# 格式：每行一個 Python regex；`#` 開頭為註解。比對前訊息會先做 NFKC 與空白折疊，
# 並另外比對「去掉所有空白」的版本。
#   - 一般行：命中視為 T2（T1 頻道擋下，提示改到正確頻道）。
#   - `T3:` 開頭：命中視為 T3（和內建 T3 字詞一樣擋下，回「此內容可能屬 T3…」）。
#
# 這是字詞告警，不是內容理解：換個說法、縮寫、錯字都擋不到。誤擋時改寫該行的排除條件，
# 不要整行刪掉；每次增刪都記錄日期與理由，每季覆核一次（見 team/policies/restricted.md）。
